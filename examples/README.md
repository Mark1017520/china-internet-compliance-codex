# Examples

本目录提供可复制的提示词样例，帮助用户快速理解该 Skill 套件适合处理哪些合规问题。

建议第一次试用时按以下顺序：

1. `ai-customer-service-launch-review.md`
2. `app-sdk-permission-review.md`
3. `marketing-lottery-review.md`
4. `oss-license-review.md`
5. `regulatory-evidence-response.md`

每个示例都包含：

- 适用 Skill
- 可直接复制到 Codex 的提示词
- 期望输出检查点
- 需要人工补充或核验的信息

请不要在公开仓库、Issue 或示例中提交真实个人信息、合同、客户数据、密钥、监管调查材料或未公开业务资料。
