# Example: App SDK 权限审查

## 适用 Skill

`$china-data-privacy-compliance` 或 `/china-compliance:app_sdk_review`

## 提示词

```text
$china-data-privacy-compliance 请审查以下 App SDK 接入方案的数据合规和权限风险：
App 名称：示例商城 App
上线地区：中国大陆
SDK 名称：示例推送 SDK、示例统计 SDK、示例客服 SDK
SDK 用途：消息推送、崩溃统计、客服会话
申请权限：设备标识符、剪贴板读取、相册、通知、网络状态
涉及数据：设备信息、App 崩溃日志、用户 ID、客服会话内容
第三方共享：SDK 服务商会接收部分设备信息和日志
用户告知：隐私政策已列出 SDK 清单，但未做弹窗单独提示
希望输出：权限最小化建议、隐私政策更新点、SDK 清单整改项、上线 gate
```

## 期望输出检查点

- 是否按权限必要性逐项评估
- 是否识别剪贴板、设备标识符、相册等高敏权限或高关注权限
- 是否要求 SDK 清单、隐私政策、第三方共享说明保持一致
- 是否提示初始化时机、用户同意前不得提前采集
- 是否给出下架、替换、延后接入或灰度策略

## 需人工补充

- SDK 官方文档和实际采集字段
- 初始化代码位置
- Android/iOS 权限弹窗文案
- SDK 服务商合同或数据处理条款
