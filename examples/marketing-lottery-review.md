# Example: 营销抽奖活动审查

## 适用 Skill

`$china-advertising-marketing` 或 `/china-compliance:ad_marketing_review`

## 提示词

```text
$china-advertising-marketing 请审查以下营销抽奖活动是否可以上线：
活动名称：618 会员抽奖活动
上线地区：中国大陆
活动对象：平台注册用户
活动机制：用户完成每日签到、分享活动页或购买指定商品后获得抽奖次数
奖品：优惠券、会员月卡、实物礼品
概率展示：页面展示“最高可得 iPhone”，暂未展示各奖项概率
参与限制：每人每天最多 3 次
涉及数据：用户 ID、手机号、收货地址、活动参与记录
第三方：短信服务商、物流服务商
希望输出：广告营销、抽奖、个人信息、消费者权益风险和整改建议
```

## 期望输出检查点

- 是否识别概率展示、奖品规则、诱导分享、价格或优惠宣传风险
- 是否要求活动规则完整、醒目、可留存
- 是否提示中奖名单、兑奖期限、实物奖品物流和个人信息最小化
- 是否区分签到、分享、购买三类获奖资格的合规风险
- 是否给出上线前必须整改项

## 需人工补充

- 活动页面文案截图
- 各奖项数量、价值和概率
- 是否涉及未成年人或特殊商品
- 用户同意、隐私政策和第三方共享说明
