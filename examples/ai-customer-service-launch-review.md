# Example: AI 客服助手上线审查

## 适用 Skill

`$china-internet-compliance` 或 `$china-ai-algorithm-compliance`

## 提示词

```text
$china-internet-compliance 请按中国互联网公司全场景合规标准，审查以下功能是否可以上线：
功能名称：AI 客服助手
业务类型：企业 SaaS 客服
上线地区：中国大陆
用户对象：企业商家、消费者
功能描述：系统根据商家知识库、订单状态和物流信息，自动回复消费者售后咨询。复杂问题转人工。回复内容会标注“AI 生成”。
涉及数据：订单号、物流状态、售后咨询内容、商家知识库内容
第三方 SDK/API/模型：第三方大模型 API；云日志服务
是否涉及 AI/算法/AIGC：是，涉及 AIGC、自动回复和模型供应商
是否涉及 UGC/直播/评论/社交：否
是否涉及广告/营销/付费/交易：涉及售后交易信息，不做营销推荐
是否涉及未成年人：不主动面向未成年人，但无法完全排除
已具备材料：PRD、模型供应商合同摘要、隐私政策草案、日志留存方案
希望输出：上线 gate、主要风险、整改清单、责任方和需补充材料
```

## 期望输出检查点

- 是否识别 AI/AIGC、个人信息处理、供应商数据处理、交易售后和日志留存风险
- 是否区分“可上线 / 整改后可上线 / 暂不建议上线”
- 是否提示 AIGC 标识、人工兜底、误导性回复、敏感信息输入拦截
- 是否要求核验模型供应商、数据处理协议、跨境或境外 API 情况
- 是否列明产品、研发、安全、法务、客服运营责任方

## 需人工补充

- 模型 API 是否境内部署
- 是否使用用户会话继续训练模型
- 是否处理敏感个人信息
- 隐私政策、个人信息处理规则、供应商 DPA 是否已更新
