# Reference Output: 营销抽奖活动审查

## 初步结论

建议结论：整改后可上线。

活动涉及抽奖、诱导分享、奖品宣传、价格优惠、个人信息收集和第三方物流/短信服务。当前“最高可得 iPhone”但未展示概率，属于上线前必须整改项。

## 主要风险

| 风险 | 等级 | 说明 |
|---|---|---|
| 奖项概率未披露 | P1 | 概率、数量、中奖规则应清晰展示 |
| 诱导分享风险 | P1 | 分享获取抽奖次数需避免误导、强制或不当裂变 |
| 活动规则不完整 | P1 | 需明确资格、期限、兑奖、限制条件和争议处理 |
| 收货地址和手机号收集过早 | P2 | 应在中奖后最小化收集 |

## 必补材料

- 活动页面文案和截图
- 各奖项数量、价值、概率和发放规则
- 参与条件、限制条件、兑奖期限和售后规则
- 个人信息收集节点、用途和第三方共享说明
- 是否触达未成年人或特殊商品服务

## 整改建议

1. 活动页显著展示完整规则、奖项概率、奖品数量和限制条件。
2. 将手机号、地址收集延后到中奖和发货必要环节。
3. 明确分享不是强制参与条件，避免过度诱导。
4. 对优惠券、会员卡和实物奖品分别列明使用门槛、有效期和不可用范围。
5. 建立客服申诉和异常订单处理机制。

## 上线 Gate

完成概率披露、规则补齐和个人信息收集最小化后可上线。上线前应由法务/合规、运营、客服和数据隐私负责人复核。
