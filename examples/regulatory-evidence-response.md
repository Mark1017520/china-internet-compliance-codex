# Example: 监管或公安调证响应

## 适用 Skill

`$china-regulatory-response` 或 `/china-compliance:regulatory_response`

## 提示词

```text
$china-regulatory-response 请帮助梳理以下调证请求的响应材料清单和内部处理流程：
请求来源：某地公安机关
请求形式：盖章协查函
请求内容：要求提供某账号在指定时间段的登录日志、绑定手机号、订单记录和站内消息
涉及对象：平台用户账号
涉及数据：手机号、登录 IP、设备信息、订单信息、站内消息
时间要求：3 个工作日内回复
公司现有材料：协查函扫描件、账号基础信息、日志查询权限说明
希望输出：真实性核验、权限审批、数据范围最小化、证据留存、对外回复模板要点
```

## 期望输出检查点

- 是否要求核验请求主体、文书形式、范围、联系人和送达方式
- 是否提示内部审批、留痕、查询权限和双人复核
- 是否坚持数据范围最小化和与请求事项相关
- 是否提示不得擅自删除、篡改或隐瞒证据
- 是否区分可提供、需补充文书、需法务升级的材料

## 需人工补充

- 原始文书和请求依据
- 公司内部调证流程
- 数据所在系统和查询日志
- 是否涉及跨境、未成年人、敏感个人信息或历史删除请求
