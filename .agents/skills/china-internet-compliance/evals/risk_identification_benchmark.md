# V1.0.1 风险识别 Benchmark

## 使用方式

1. 选取 `prompts/test_cases.md` 中的测试用例。
2. 让 Codex 使用对应 command 输出合规结论。
3. 用 `expected_issues.json` 检查是否覆盖最低风险点。
4. 用 `legal_correctness_rubric.md` 进行人工复核评分。

## 通过标准

- 通用场景：总分 ≥ 80；
- P0/P1 高风险场景：总分 ≥ 90；
- 风险等级不得明显低估；
- 必须给出可执行 gate。

## 常见失败模式

- 把“合规建议”写成“法律已明确允许”；
- 只提示隐私风险，遗漏广告/内容/IP/支付交叉风险；
- 材料不足时仍给“低风险”；
- 对开源许可证只看 license 名称，不看使用方式；
- 对监管/公安调证没有区分原始材料、整理材料和内部分析。
