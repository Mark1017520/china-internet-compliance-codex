# Cold-start Interview — 公司化接入访谈

首次在某公司、某产品线或某业务部门使用本 Skill 时，应先完成访谈，形成 `COMPLIANCE_PROFILE.md`。

## 1. 公司与业务基本信息

1. 公司主要业务类型是什么？例如内容、社交、直播、游戏、电商、本地生活、SaaS、AI、金融导流、工具类 App 等。
2. 是否面向中国大陆 C 端用户？是否面向未成年人？
3. 是否涉及境外用户、境外部署、境外供应商、境外模型或数据出境？
4. 是否有高监管业务，如游戏、医疗、教育、招聘、房产、金融、支付、网络出版、直播等？

## 2. 产品与技术架构

1. 主要产品形态：App、Web、小程序、SDK、API、开放平台、企业服务、私有化部署？
2. 是否有推荐算法、个性化推送、搜索排序、AIGC、AI Agent、自动化决策？
3. 是否有 UGC、评论、直播、私信、群聊、社区、内容分发？
4. 是否使用第三方 SDK、API、云服务、大模型、外部数据源？

## 3. 数据与安全

1. 数据分类分级标准是什么？
2. 哪些数据属于敏感个人信息、重要数据或公司高敏数据？
3. 是否已有 SDK 清单、个人信息清单、数据地图、DPIA/PIA 流程？
4. 数据出境由哪个团队审批？

## 4. 风险偏好与审批矩阵

1. 哪些事项必须阻断上线？
2. 哪些事项需要法务、隐私、安全、开源委员会、管理层审批？
3. P0/P1/P2/P3 在公司内部如何定义？
4. 是否允许带风险灰度？例外审批有效期多长？

## 5. 输出偏好

1. 常用输出形式：评审结论、风险表、上线 gate、整改清单、管理层摘要、Excel台账？
2. 是否需要中英双语？
3. 是否要适配内部项目管理系统字段？
4. 是否有历史优秀模板或固定表述？

## 6. 生成 Profile

访谈后生成：

- `COMPLIANCE_PROFILE.md`
- `RISK_CALIBRATION.md`
- `ESCALATION_MATRIX.md`
- `APPROVAL_WORKFLOW.md`
- `DATA_CLASSIFICATION.md`
