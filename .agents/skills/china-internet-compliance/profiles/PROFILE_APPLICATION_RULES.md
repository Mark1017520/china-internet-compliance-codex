# Profile Application Rules — 公司 Profile 适用规则

## 1. 读取顺序

1. 若存在 `profiles/COMPLIANCE_PROFILE.md`，优先读取。
2. 若不存在，使用模板中的默认规则，并在输出中提示“尚未配置公司 Profile”。
3. 若公司 Profile 与通用规则冲突，优先适用更严格标准。

## 2. 输出要求

每次使用 Profile 时，在结论中说明：

- 适用的公司内部规则或风险偏好；
- 与通用法律规则的关系；
- 是否存在规则缺口；
- 是否需要补充公司内部审批。

## 3. 禁止事项

- 不得把公司内部风险偏好伪装为法律强制要求。
- 不得把通用法律义务降低为公司可自行豁免事项。
- 不得在缺少 Profile 时假设公司审批流程。
