# Approval Workflow Template — 审批流程模板

## 1. 常规产品上线

1. 产品提交 PRD / 需求说明。
2. Codex 初审并输出风险等级。
3. 法务/隐私/安全/开源等按触发场景复核。
4. 产品和研发完成整改。
5. 上线 gate 确认。
6. 上线后监测。

## 2. P0/P1 事项

- 必须形成书面评审记录。
- 必须明确责任人和关闭标准。
- 未关闭前不得默认上线。
- 例外上线需说明有效期、审批人、临时控制措施和复核日期。

## 3. 监管/公安/诉讼响应

- 法务统一入口。
- 核验函件真实性、主体、范围、期限。
- 按最小必要原则准备材料。
- 记录检索、导出、审批和交付链路。
- 对技术字段、日志、代码、订单、金额、个人信息进行解释说明。
