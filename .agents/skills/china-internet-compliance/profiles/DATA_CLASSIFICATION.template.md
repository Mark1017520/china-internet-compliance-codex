# Data Classification Template — 数据分类分级模板

| 数据类别 | 示例 | 默认等级 | 典型控制措施 |
|---|---|---|---|
| 公开数据 | 已公开页面、公开规则 | L1 | 基础访问控制 |
| 内部数据 | 内部配置、普通运营数据 | L2 | 权限控制、日志留痕 |
| 个人信息 | 手机号、邮箱、设备标识、账号ID、订单信息 | L3 | 告知同意、最小必要、访问控制 |
| 敏感个人信息 | 精准定位、身份证件、金融账户、未成年人信息、生物识别 | L4 | 单独同意、PIA、加密、严格权限 |
| 重要业务数据 | 核心交易、风控、支付、平台治理、算法训练核心数据 | L4/L5 | 专项审批、脱敏、审计 |
| 密钥与凭证 | token、API key、私钥、数据库密码 | L5 | 禁止明文、密钥系统、轮换、审计 |
| 监管/诉讼证据 | 调证材料、日志、证据包、调查记录 | L5 | 法务审批、保全、链路留痕 |
