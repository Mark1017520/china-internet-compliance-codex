# 全场景检查清单

## A. 通用产品上线/功能调整

必问问题：
1. 功能解决什么业务问题？是否对外开放？是否灰度？是否可回滚？
2. 用户对象是谁：消费者、企业客户、商家、开发者、主播、达人、员工、未成年人？
3. 上线地区是否包括中国大陆？是否跨境？
4. 是否改变用户协议、隐私政策、平台规则、商家/开发者/创作者协议？
5. 是否新增权限、新增数据、新增第三方、新增自动化决策、新增对外展示？
6. 是否存在日志、投诉入口、开关、监控、应急预案？

输出重点：场景分类、风险等级、上线 gate、需补充材料、责任方。

## B. 数据与隐私

必问问题：
1. 收集哪些字段？是否个人信息/敏感个人信息/重要数据？
2. 数据来源：用户主动提交、系统采集、第三方提供、公开抓取、企业客户导入、商家导入、模型生成？
3. 处理目的是否明确、合理、最小必要？
4. 是否有告知、同意、单独同意、撤回路径？
5. 是否共享给第三方 SDK/API/模型/供应商？
6. 是否跨境？是否有出境路径、接收方、数据字段、合同？
7. 是否做 PIA/DPIA、数据分类分级、日志留存、删除机制？

高风险信号：人脸、声音、精准定位、身份证、支付/金融账户、医疗健康、生物识别、行踪轨迹、未成年人、大规模画像、跨境传输。

## C. App/SDK/终端权限/网络安全

必问问题：
1. 新增了哪些 App 权限？是否与功能必要相关？
2. 是否接入第三方 SDK？SDK 是否存在自启动、关联启动、超范围采集？
3. 隐私政策、SDK清单、权限说明、弹窗是否更新？
4. 是否影响登录、支付、企业后台、API、权限、日志、风控？
5. 是否需要安全测试、等保、漏洞扫描、渗透测试、灰度监控？
6. 是否存在密钥、token、配置文件、日志敏感信息泄露？

## D. AI/算法/AIGC/智能体

必问问题：
1. 是推荐/排序/搜索/过滤/调度算法，还是生成式AI/深度合成/智能体/自动化决策？
2. 是否面向境内公众？是否具有舆论属性或社会动员能力？
3. 模型来源：自研、境内第三方、境外第三方、开源模型？
4. 输入数据是否包含个人信息、企业客户数据、用户内容、敏感信息、商业秘密？
5. 输出是否可能影响交易、信用、排序、价格、权益、账号处罚、就业/信贷/教育机会？
6. 是否设置用户提示、AI标识、投诉纠错、人工复核、日志留存？
7. 是否需要算法备案、生成式AI备案、安全评估、内容标识？
8. 供应商是否会将输入/输出用于训练？是否可关闭训练？是否跨境？

## E. 内容、社区、社交、直播与平台治理

必问问题：
1. 是否允许用户发布、评论、直播、上传、转发、私信、群聊、关注、打赏？
2. 是否存在内容审核、举报、申诉、账号处罚、禁言、封禁机制？
3. 是否涉及新闻资讯、公众账号、直播、短视频、网络表演、网络出版、音视频节目等强监管内容？
4. 是否涉及未成年人、直播打赏、主播、达人、KOL？
5. 是否有违法信息、诈骗引流、黑灰产、侵权内容处置流程？
6. 是否保留日志、审核记录、处罚记录、投诉处理记录？

## F. 广告营销、增长与商业化

必问问题：
1. 是否构成商业广告？广告是否可识别？是否显著标注广告？
2. 是否使用极限词、虚假对比、保证性承诺、误导性价格？
3. 是否涉及医疗、药品、保健品、金融、教育、招商加盟、烟草电子烟等特殊广告？
4. 活动规则是否完整：资格、时间、奖品、概率、限制、退款、争议处理？
5. 是否涉及充值、返利、概率、抽奖、排名、任务奖励、裂变、未成年人？
6. 短信/电话/邮件/Push营销是否有授权、退订和频控？

## G. 网络交易、电商、本地生活与平台责任

必问问题：
1. 是否涉及商品/服务发布、商家/服务者入驻、交易、支付、售后、评价、履约？
2. 是否清晰区分平台、商家、服务者、达人、第三方服务商责任？
3. 是否有规则公示、规则修改通知、处罚、申诉、通知、证据留存？
4. 是否涉及知识产权投诉、重复侵权人、notice-and-takedown？
5. 商品/服务是否需要资质、许可、审查或禁限售控制？
6. 价格、优惠、库存、发货、退款、售后、评价是否真实清晰？

## H. 游戏、虚拟资产与未成年人

必问问题：
1. 是否构成网络游戏或类游戏玩法？是否需要版号、备案、运营资质或小游戏平台规则审查？
2. 是否涉及实名、防沉迷、时长限制、充值限制、未成年人保护？
3. 是否涉及抽卡、盲盒、概率道具、宝箱、随机奖励？是否公示概率与规则？
4. 虚拟币/虚拟道具是否可购买、转让、提现、兑换现金或实物？
5. 排行榜、PK、竞赛、任务、返利是否可能诱导消费或赌博化？
6. 是否设置退款、投诉、家长监护、异常交易风控？

## I. 支付、资金结算与金融相邻

必问问题：
1. 是否接触用户资金、预付款、余额、钱包、分账、提现、退款？
2. 是否由持牌机构提供支付/清算/金融服务？我方角色是技术服务、导流、代理、合作方还是资金处理方？
3. 是否存在二清、资金池、沉淀资金、无牌支付或非法金融活动风险？
4. 是否涉及信贷、保险、理财、基金、证券、征信、评分、反欺诈？
5. 金融广告、导流文案、收益承诺、风险提示是否合规？
6. 是否涉及敏感金融信息、自动化决策、歧视或拒绝服务？

## J. 企业服务、SaaS/PaaS/IaaS/API/开放平台

必问问题：
1. 是否处理企业客户上传的数据、员工数据、终端用户数据、经营数据？
2. 客户与平台之间是委托处理、共同处理、独立处理还是工具提供关系？
3. 是否提供 API、SDK、插件、应用市场、开发者平台、私有化部署、白标服务？
4. 是否有开发者/第三方应用审核、权限最小化、数据访问日志、下架机制？
5. 是否需要 DPA、SLA、安全附件、分包披露、审计权、数据删除返还？
6. 是否对外交付代码、镜像、SDK、插件或部署包，触发开源许可证义务？

## K. 知识产权、开源与商业秘密

必问问题：
1. 是否复制或参考第三方/竞品代码、文档、主题、模板、页面、字段、接口？
2. 是否使用第三方素材、字体、图片、音乐、视频、图标？授权范围是否覆盖商业使用、修改、分发、嵌入？
3. 是否引入开源组件？许可证是什么？使用方式是什么？
4. 是否修改源码、静态/动态链接、作为服务提供、对外分发、私有化部署？
5. 是否需要公开源码、提供NOTICE、保留版权声明、提供许可证文本？
6. 是否存在内部代码、商业秘密、密钥、token、客户信息泄露？

## L. 跨境合规

必问问题：
1. 用户、服务器、供应商、模型、客服、研发、日志、备份是否跨境？
2. 是否向境外提供个人信息、重要数据、业务数据或客户数据？
3. 是否需要安全评估、标准合同、认证、PIA、单独同意或豁免/便利化判断？
4. 境外接收方是否有数据保护、保密、删除、分包、审计和安全事件义务？
5. 是否涉及境外法律、制裁、出口管制、数据本地化或模型服务地区限制？

## M. 监管/公安/诉讼响应

必问问题：
1. 函件主体、案由、法律依据、要求事项是否明确？
2. 要提供哪些字段、账号、日志、订单、金额、内容、时间范围？
3. 当前材料是否超范围？是否包含无关客户、内部敏感信息、密钥、token、secureCode、源代码？
4. 数据口径是否能与原始日志、整理表、订单表相互对应？
5. 是否需要技术说明、字段解释、流程图、对外口径、内部审批？
6. 是否保留导出记录、盖章版本、发送记录、签收记录？
