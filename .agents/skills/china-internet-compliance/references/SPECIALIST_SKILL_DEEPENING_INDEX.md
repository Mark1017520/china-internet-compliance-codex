# V1.0.3 专项 Skill 深化索引

本文件用于说明 V1.0.3 对 11 个专项 Skill 的深化原则。主控 Skill 在路由到专项 Skill 时，应优先读取该专项目录下的 `SKILL.md` 和 `PLAYBOOK.md`。

## 专项深化要求

每个专项 Skill 必须包含：

1. 适用场景；
2. 必需输入字段；
3. 专项判断树；
4. P0/P1 触发条件；
5. 证据材料清单；
6. 交叉场景路由；
7. 推荐模板；
8. 输出格式；
9. 质量门槛。

## 主控路由原则

- 单一场景：由主控 Skill 直接路由到一个专项 Skill。
- 复合场景：由主控 Skill 先输出总控结论，再调用两个以上专项 Skill。
- 高风险场景：如果出现 P0/P1 信号，必须列出人工复核、证据材料、关闭标准。
- 材料不足：不得降低风险等级，只能输出条件性结论。

## 复合场景优先级

1. 数据/隐私、AI/算法、监管响应、支付/金融、未成年人、开源/IP 属于高优先级专项。
2. 广告营销、内容治理、平台交易、产品上线属于高频交叉专项。
3. 供应商合同常作为支撑专项，需与数据、AI、开源、安全、监管响应联动。
