# AI、数据与模型合规规则

## 1. AI能力类型识别

| 类型 | 示例 | 重点风险 |
|---|---|---|
| 推荐/排序/搜索 | 信息流、商品排序、内容推荐、候选人排序 | 算法备案、透明度、关闭入口、歧视、大数据杀熟、诱导沉迷 |
| 自动化决策 | 风控拒绝、账号处罚、定价、权益分配、信贷/招聘/教育机会 | 个人权益重大影响、人工复核、解释权、歧视 |
| 生成式AI | AI文案、AI图片、AI客服、AI总结、AI编程、AI生成广告 | 备案、安全评估、训练数据、输出侵权/违法、AI标识 |
| 深度合成 | 换脸、拟声、数字人、虚拟主播、视频合成 | 肖像/声音授权、显著标识、欺骗误导、虚假信息 |
| 智能体/Agent | 自动调用工具、检索文件、发消息、下单、改配置 | 权限边界、人工确认、日志、数据泄露、不可逆操作 |
| RAG/知识库 | 企业文档问答、客服知识库、法规检索 | 数据权限、保密、幻觉、来源引用、越权检索 |

## 2. AI输入数据检查

必须确认：
- 输入是否包含个人信息、敏感个人信息、客户数据、商业秘密、源代码、密钥、未公开合同、监管/诉讼材料。
- 输入是否会被第三方模型供应商保存、用于训练、人工审核或转移出境。
- 是否有脱敏、最小化、权限控制、日志留存和删除机制。
- 是否向用户说明AI处理方式、目的、范围和风险。

## 3. AI输出风险检查

必须确认：
- 输出是否可能构成法律、医疗、金融、招聘、教育等高风险建议。
- 输出是否可能侵犯版权、商标、肖像权、名誉权、个人信息权益或商业秘密。
- 输出是否可能产生虚假广告、误导性承诺、违法有害信息、歧视内容。
- 输出是否被直接发布到公开场景，还是需要人工确认。
- 是否有投诉纠错、删除更正、人工复核、追踪日志。

## 4. AI标识与透明度

关注：
- 是否需要显式标识：界面提示、内容水印、文字说明、音频提示。
- 是否需要隐式标识：文件元数据、水印、可追溯标记。
- 用户是否能够知道自己正在与AI交互。
- 用户是否能关闭个性化推荐或拒绝自动化决策的非必要影响。

## 5. 供应商/模型合同检查

重点条款：
- 输入/输出数据归属和使用范围。
- 是否用于模型训练、改进、人工审核。
- 数据存储地区、跨境传输、分包处理。
- 安全措施、日志、删除、退出迁移。
- 知识产权归属、侵权赔偿、输出保证限制。
- 服务可用性、封禁、限流、模型变更通知。
- 合规协助、备案材料、安全评估材料。

## 6. 上线 Gate

高风险AI功能上线前通常应完成：
1. AI功能说明与用户提示；
2. 输入/输出数据字段清单；
3. 供应商合同/DPA/训练关闭确认；
4. 内容安全与违法有害过滤；
5. AI标识方案；
6. 人工复核和投诉纠错机制；
7. 备案/安全评估/算法透明度判断；
8. 灰度、监控、回滚和日志留存。
