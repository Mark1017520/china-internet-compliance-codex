# 风险分级矩阵

## P0 阻断

适用：明显违法、强许可缺失、重大数据/安全/IP/金融/未成年人/证据风险，或上线后难以补救。

典型情形：
- 无法提供合法性基础即收集敏感个人信息或未成年人信息。
- 无牌开展支付、清算、信贷、保险、理财、征信等强许可业务。
- 未完成必要安全评估/备案即向公众提供高影响算法/AIGC能力。
- 明显复制第三方核心代码/素材/商标/受保护内容并对外分发。
- 监管/公安/诉讼材料提供超范围且包含无关个人信息、密钥、源代码或商业秘密。
- 内容平台或直播功能缺失基本审核、举报、处置机制。

默认动作：阻断上线或暂停提供；法务/合规/安全/业务负责人专项评审；必要时外部律师确认。

## P1 高风险

适用：可能触发备案、评估、监管问询、重大投诉、群体性消费者争议、侵权索赔或重大合同违约。

典型情形：
- 有个人信息共享/出境但告知、同意、DPA、PIA不完整。
- AI模型供应商使用用户输入训练，且未明示或未关闭。
- 广告活动涉及价格、抽奖、特殊行业、未成年人，但规则不清。
- 游戏/虚拟资产有充值、概率、排行榜、PK但规则/概率/防沉迷不足。
- 开源组件许可证存在强传染或商业限制，使用方式未核实。
- 企业客户数据被第三方插件/API访问，权限和日志不足。

默认动作：整改后上线；设置上线 gate；明确 owner、期限、回滚与监控。

## P2 中风险

适用：材料不足或流程、文案、授权、合同、留痕存在瑕疵，但可通过补充说明、配置控制、灰度范围、协议更新降低风险。

典型情形：
- 个人信息字段清单或数据流向不完整，但未发现敏感字段。
- 活动规则缺少争议处理、退款、奖品限制、时间说明。
- 使用第三方素材但授权文件待补充。
- SDK清单、隐私政策、页面提示需要同步更新。
- 内容治理机制存在但缺少部分日志或客服话术。

默认动作：补充材料后可上线或灰度上线；上线后补齐监控与留痕。

## P3 低风险

适用：常规文案优化、低影响流程调整、内部管理优化，不新增个人信息、第三方、算法、内容传播、交易、资金、对外分发代码等核心风险。

典型情形：
- 内部后台展示字段调整，未新增数据和权限。
- 非营销性质的按钮文案优化。
- 已有功能的可回滚配置调整，不改变用户权益和数据处理方式。

默认动作：可上线，保留评审记录。

## 不得直接给 P3 的情形

- 事实不足且无法判断是否涉及个人信息、第三方、AI、交易、内容、资金、未成年人或开源。
- 用户仅提供一句功能名称，但无业务流程、数据字段、第三方和上线地区。
- 涉及监管高变化领域但没有备案/资质/法律依据确认。
