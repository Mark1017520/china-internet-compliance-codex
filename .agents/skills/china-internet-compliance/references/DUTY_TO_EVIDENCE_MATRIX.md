# Duty-to-Evidence Matrix — 义务与证据材料矩阵

## 1. 使用方法

每当识别到合规义务，应同时列出需要的证据材料。没有证据，不应直接给出“已满足”结论。

## 2. 通用矩阵

| 合规义务/风险 | 需要的证据材料 | 常见责任方 | 缺失时的默认判断 |
|---|---|---|---|
| 个人信息最小必要 | 数据字段清单、采集点、用途说明、前端页面截图、后端日志字段 | 产品/研发/隐私 | 不得判断为已满足 |
| 敏感个人信息单独同意 | 单独同意页面、授权日志、撤回路径、隐私政策条款 | 产品/研发/隐私 | P1 或 P0 视数据敏感程度 |
| 第三方SDK共享 | SDK清单、权限清单、DPA/合同、SDK隐私政策、初始化时机 | 研发/安全/隐私/采购 | P1，需上线 gate |
| 数据出境 | 出境字段、接收方、国家/地区、目的、机制、合同/评估材料 | 隐私/安全/业务 | 不得上线前默默出境 |
| 算法推荐/自动化决策 | 算法用途、影响范围、关闭选项、解释机制、备案判断 | 产品/算法/合规 | P1，需专项判断 |
| AIGC/深度合成 | 生成内容类型、标识方案、模型供应商、内容安全策略、日志 | AI产品/研发/内容安全 | P1，需标识和内容安全 gate |
| 内容治理 | 审核规则、举报入口、处置流程、申诉机制、留痕 | 运营/内容安全/法务 | P1/P2 |
| 广告营销 | 活动规则、页面文案、奖品、概率、价格、达人关系、资质 | 运营/商业化/法务 | P1/P2 |
| 交易/平台责任 | 平台规则、商家资质、投诉售后、评价机制、交易留痕 | 产品/运营/法务 | P1/P2 |
| 游戏/虚拟资产 | 版号/资质判断、概率公示、未成年人限制、充值规则 | 游戏/运营/法务 | P0/P1 |
| 支付/分账/金融导流 | 资金流图、通道合同、牌照/资质、用户协议、风控机制 | 财务/支付/法务 | P0/P1 |
| 开源许可证 | 依赖清单、许可证文本、使用方式、修改记录、分发方式、SBOM | 研发/开源办/法务 | P1/P2 |
| 竞品/第三方素材 | 来源证明、授权文件、生成记录、设计稿、相似性对比 | 产品/设计/法务 | P1/P2 |
| 公安/监管调证 | 调证函、范围、数据表、日志、最小必要说明、审批记录 | 法务/安全/研发 | P0/P1 |

## 3. 输出要求

对 P0/P1 项，必须输出：

- 已有证据；
- 缺失证据；
- 未取得证据前的判断；
- 上线或对外提供材料前的 gate。
