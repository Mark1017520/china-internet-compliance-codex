# 示例调用 Prompt

## 通用产品功能

```text
$china-internet-compliance 请按中国互联网公司全场景合规标准审查以下功能：
功能名称：
业务场景：
上线地区：
用户对象：
功能描述：
涉及数据：
第三方：
是否涉及AI/算法/内容/广告/交易/支付/游戏/开源：
请输出风险等级、业务场景分类、主要风险、法律依据、待确认问题、整改建议和上线 gate。
```

## AI 功能

```text
$china-internet-compliance 审查一个面向C端用户的AI图片生成工具，用户输入提示词并上传人像照片，系统调用境外大模型生成头像，可一键发布到社区。请从中国互联网全场景合规角度评估。
```

## 广告营销活动

```text
$china-internet-compliance 审查一个充值返利和抽奖活动，用户充值后获得抽奖次数，有机会获得虚拟道具和现金券，活动面向中国大陆用户。请给出上线前必须整改项。
```

## 企业服务/API

```text
$china-internet-compliance 审查一个开放API，允许第三方开发者读取企业客户的用户列表、订单、客服记录，并在开发者应用中处理。请分析数据、平台责任、合同、IP和安全风险。
```

## 监管响应

```text
$china-internet-compliance 请审查以下公安调证材料是否适合对外提供，并列出超范围、需脱敏、需补充说明的内容。
```
