# /china-compliance:ai_algorithm_review

## 1. 命令契约

- 命令名称：`/china-compliance:ai_algorithm_review`
- 任务类型：AI、算法、AIGC、深度合成和 Agent 审查
- 适用场景：推荐算法、生成式 AI、数字人、语音/图像合成、自动化决策、RAG、工具调用 Agent
- 目标输出：备案/标识/安全评估触发、数据来源、模型供应商、人工复核、日志和上线 gate

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| AI 能力类型、用户对象、是否面向公众 | 缺失则无法判断备案/标识 |
| 模型来源、部署区域、供应商、训练/微调数据 | 缺失则 P1 |
| 输入输出内容、是否生成/合成/推荐/排序 | 缺失则不得判低风险 |
| 标识方案、人工复核、申诉纠错、日志留存 | 缺失则上线前整改 |

## 3. 执行流程

1. 判断能力类型：算法推荐、AIGC、深度合成、自动化决策、Agent。
2. 判断是否公共服务、是否具有舆论属性或社会动员能力。
3. 检查备案、安全评估、AIGC 标识、模型供应商责任。
4. 检查数据来源、训练授权、个人信息和敏感内容过滤。
5. 检查人工兜底、申诉纠错、日志留存和滥用防护。

## 4. 缺失材料处理

- 模型供应商不明：P1。
- 是否公众服务不明：按公众服务保守判断。
- 输出可能影响权益但无人工复核：P1。
- 涉及医疗、金融、未成年人、招聘筛选：升级专项复核。

## 5. 输出格式

```markdown
# AI/算法审查
## 1. AI 能力分类
## 2. 备案/标识/评估触发
## 3. 数据与模型供应商
## 4. 输出风险和人工兜底
## 5. 整改清单和上线 Gate
```

## 6. 质量门槛

- 必须判断备案、AIGC 标识和安全评估触发。
- 必须覆盖模型供应商和数据来源。
- 必须输出人工复核和日志要求。
