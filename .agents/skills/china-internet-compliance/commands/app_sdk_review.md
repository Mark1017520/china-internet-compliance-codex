# /china-compliance:app_sdk_review

## 1. 命令契约

- 命令名称：`/china-compliance:app_sdk_review`
- 任务类型：App 权限和 SDK 合规安全审查
- 适用场景：新 SDK 接入、权限变更、版本上架、监管通报整改、隐私检测
- 目标输出：权限必要性、SDK 数据共享、初始化时机、隐私清单、整改和上架 gate

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| SDK 名称、版本、用途、服务商、隐私政策链接 | 缺失则不得通过 |
| 权限列表、触发时机、系统弹窗文案 | 缺失则列 P1 |
| 实际采集字段、发送域名、初始化代码位置 | 缺失则建议抓包/代码核验 |
| App 隐私政策、SDK 清单、个人信息清单 | 缺失则上线前整改 |

## 3. 执行流程

1. 按 SDK 逐项建立清单。
2. 对权限做必要性判断：业务场景、触发时机、替代方案。
3. 对数据共享做字段级核验。
4. 检查同意前初始化、静默采集、超范围调用、频繁索权。
5. 输出上架前整改和复测证据。

## 4. 缺失材料处理

- 无 SDK 版本号：不得完成审查。
- 无实际采集证据：输出抓包和代码核验任务。
- 剪贴板、精确位置、通讯录、相册、设备标识符不明：默认 P1。

## 5. 输出格式

```markdown
# App/SDK 审查
## 1. SDK 与权限清单
## 2. 必要性判断
## 3. 数据共享和初始化核验
## 4. 隐私政策/清单整改
## 5. 上架 Gate
```

## 6. 质量门槛

- 必须按 SDK 和权限逐项输出。
- 必须区分声明用途和实际采集。
- 必须给出复测证据要求。
