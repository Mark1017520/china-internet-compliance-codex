# /china-compliance:game_review

## 1. 命令契约

- 命令名称：`/china-compliance:game_review`
- 任务类型：游戏、虚拟资产和概率玩法审查
- 适用场景：小游戏、抽卡、盲盒、虚拟币、虚拟道具、排行榜、打赏、未成年人
- 目标输出：资质/版号触发、概率公示、虚拟资产规则、防沉迷、充值退款和赌博化风险

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| 游戏形态、上线渠道、是否联网、是否收费 | 缺失则无法判断资质 |
| 虚拟币/道具/抽卡/概率/交易/转赠规则 | 缺失则 P1 |
| 未成年人识别、防沉迷、充值限额、退款 | 缺失则 P1 |
| 活动规则、排行榜、奖励、提现或兑换 | 涉及财产权益时必需 |

## 3. 执行流程

1. 判断是否构成网络游戏或游戏化活动。
2. 检查资质、版号、渠道规则和未成年人机制。
3. 审查虚拟资产发行、购买、使用、过期、退款和转让。
4. 审查概率公示、抽取记录、活动公平性和赌博化风险。
5. 输出上线 gate 和风控监控指标。

## 4. 缺失材料处理

- 是否收费或兑换不明：P1。
- 抽卡概率不明：P1。
- 未成年人机制缺失：P1/P0。
- 可提现、可交易或可兑换现金等价物：升级支付/金融复核。

## 5. 输出格式

```markdown
# 游戏/虚拟资产审查
## 1. 游戏形态和资质
## 2. 虚拟资产和概率玩法
## 3. 未成年人和充值退款
## 4. 赌博化/金融化风险
## 5. Gate 和监控
```

## 6. 质量门槛

- 必须判断未成年人、防沉迷和充值退款。
- 必须审查概率和虚拟资产规则。
- 必须识别提现、交易、兑换导致的升级风险。
