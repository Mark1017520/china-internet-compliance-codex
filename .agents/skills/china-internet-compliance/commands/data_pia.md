# /china-compliance:data_pia

## 1. 命令契约

- 命令名称：`/china-compliance:data_pia`
- 任务类型：个人信息保护影响评估和数据处理审查
- 适用场景：个人信息、敏感个人信息、委托处理、共同处理、第三方共享、公开披露、跨境、用户权利
- 目标输出：PIA 触发判断、合法性基础、告知同意、单独同意、出境路径、整改清单

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| 数据字段、数据主体、处理目的、处理方式、保存期限 | 缺失则 P1 待确认 |
| 接收方、供应商、SDK/API、境外接收方 | 共享/委托/跨境不清则不得判低风险 |
| 用户告知、同意、单独同意、撤回路径 | 缺失则列入上线前整改 |
| 安全控制、权限、日志、删除/更正/导出路径 | 缺失则列入证据缺口 |

## 3. 执行流程

1. 建立数据处理活动表。
2. 判断是否触发 PIA、单独同意、出境评估/标准合同/认证。
3. 检查最小必要、目的限定、保存期限和用户权利。
4. 检查第三方角色：委托、共同处理、独立处理、境外接收。
5. 输出隐私政策、弹窗、SDK 清单、DPA 和安全整改项。

## 4. 缺失材料处理

- 数据字段不完整：不得给 PIA 结论。
- 第三方接收方不明：按 P1 处理。
- 跨境不明：按“待跨境核验”处理。
- 未提供用户权利路径：列为上线前整改。

## 5. 输出格式

```markdown
# 数据隐私/PIA 审查
## 1. 数据处理活动表
## 2. PIA 与单独同意触发判断
## 3. 第三方/跨境分析
## 4. 用户告知与权利路径
## 5. 风险与整改
## 6. PIA 结论和 Gate
```

## 6. 质量门槛

- 必须输出数据字段级表格。
- 必须判断 PIA、单独同意和跨境路径。
- 不得用“已写隐私政策”替代实际告知同意审查。
