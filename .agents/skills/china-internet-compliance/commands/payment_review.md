# /china-compliance:payment_review

## 1. 命令契约

- 命令名称：`/china-compliance:payment_review`
- 任务类型：支付和金融相邻能力审查
- 适用场景：充值、提现、余额、分账、钱包、支付通道、金融导流、信用评分、保险/理财广告
- 目标输出：资金流、持牌主体、用户资金权益、退款、金融广告、适当性和风控责任

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| 资金流图、支付通道、收款主体、结算路径 | 缺失则 P1 |
| 余额/钱包/充值/提现/分账规则 | 缺失则不得判低风险 |
| 金融产品提供方、牌照、跳转/导流方式 | 涉金融时必需 |
| 退款、对账、异常交易、风控和客服流程 | 缺失则上线前整改 |

## 3. 执行流程

1. 绘制资金流和信息流。
2. 判断是否触发持牌支付、资金池、二清、金融导流或金融广告风险。
3. 审查用户资金权益、退款提现、收费、对账和异常处理。
4. 审查金融产品宣传、适当性、风险提示和第三方责任。
5. 输出阻断项和合同/系统整改项。

## 4. 缺失材料处理

- 无资金流图：P1。
- 收款主体不明：P1/P0。
- 涉金融产品但无持牌主体：P0/P1。
- 用户余额可沉淀但规则不清：P1。

## 5. 输出格式

```markdown
# 支付/金融相邻审查
## 1. 资金流和主体
## 2. 持牌/二清/资金池判断
## 3. 用户权益和退款提现
## 4. 金融广告和导流
## 5. Gate
```

## 6. 质量门槛

- 必须输出资金流图文字版。
- 必须识别持牌主体和资金责任。
- 涉金融产品必须审查风险提示和适当性。
