# /china-compliance:oss_review

## 1. 命令契约

- 命令名称：`/china-compliance:oss_review`
- 任务类型：开源许可证、第三方素材和代码交付审查
- 适用场景：开源依赖、Docker 镜像、私有化部署、SDK 分发、字体/图片/素材、竞品复用、公开仓库
- 目标输出：许可证义务、分发触发、源码/notice 要求、替代方案、泄密风险和交付 gate

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| 组件名、版本、许可证、使用方式、是否修改 | 缺失则不得通过 |
| 交付形态：SaaS、源码、SDK、镜像、私有化 | 缺失则无法判断义务 |
| SBOM/SCA、包管理文件、镜像内容 | 缺失则输出扫描任务 |
| 第三方素材授权、字体、图片、竞品内容来源 | 涉素材时必需 |

## 3. 执行流程

1. 建立组件和素材清单。
2. 按使用方式判断许可证义务：使用、修改、链接、分发、网络服务、镜像交付。
3. 标记高风险许可证和未知许可证。
4. 检查 NOTICE/LICENSE、源码披露、商业授权和客户合同一致性。
5. 检查公开仓库泄密、密钥、客户代码和商业秘密。

## 4. 缺失材料处理

- 无版本号或许可证文本：P1。
- AGPL/SSPL/Elastic 等高风险许可证：升级复核。
- 对外交付但无第三方软件清单：P1。
- 素材无授权证明：P1/P0。

## 5. 输出格式

```markdown
# 开源/IP 审查
## 1. 组件/素材清单
## 2. 许可证义务和触发条件
## 3. 高风险项和替代方案
## 4. Notice/源码/合同整改
## 5. 交付 Gate
```

## 6. 质量门槛

- 必须按组件输出义务。
- 必须区分 SaaS 与分发/私有化部署。
- 不得在无版本号时给确定许可证结论。
