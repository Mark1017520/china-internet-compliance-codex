# /china-compliance:ad_marketing_review

## 1. 命令契约

- 命令名称：`/china-compliance:ad_marketing_review`
- 任务类型：广告、营销、增长活动审查
- 适用场景：广告文案、KOL/KOC、Push/SMS、抽奖、优惠券、会员权益、直播带货、价格宣传
- 目标输出：广告标识、特殊行业资质、宣传依据、概率规则、退订机制、个人信息和消费者权益风险

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| 活动规则、页面文案、素材、投放渠道、目标用户 | 缺失则不出最终结论 |
| 奖品/权益/价格/概率/限制条件 | 缺失则 P1 |
| 广告主、平台、达人、代理商责任分工 | KOL/直播场景必需 |
| 特殊行业资质和证明材料 | 医疗、金融、教育、招商等场景必需 |

## 3. 执行流程

1. 判断是否构成广告或商业营销。
2. 核对广告标识、显著提示、特殊行业资质和禁限词。
3. 审查活动规则、概率、奖品、价格、限制条件、退款/退订。
4. 审查个人信息收集和第三方共享。
5. 输出上线前必须修改的文案和规则。

## 4. 缺失材料处理

- 无活动规则：P1。
- 无概率/奖品数量：抽奖类 P1。
- 特殊行业资质不明：P0/P1。
- Push/SMS 无退订：P1。

## 5. 输出格式

```markdown
# 广告营销审查
## 1. 活动/广告事实
## 2. 文案和资质审查
## 3. 规则/概率/价格/权益
## 4. 用户告知和个人信息
## 5. 修改清单和 Gate
```

## 6. 质量门槛

- 必须逐条指出需修改文案或规则。
- 抽奖/概率活动必须审查概率和奖品数量。
- Push/SMS 必须审查退订和触达依据。
