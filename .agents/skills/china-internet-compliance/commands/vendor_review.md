# /china-compliance:vendor_review

## 1. 命令契约

- 命令名称：`/china-compliance:vendor_review`
- 任务类型：供应商、SDK/API、模型、云服务和外包合同审查
- 适用场景：新供应商准入、DPA、SLA、模型 API、云服务、外包开发、数据处理协议
- 目标输出：数据角色、转委托、跨境、安全、IP、服务等级、责任上限、退出删除和上线 gate

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| 供应商名称、服务内容、接触数据、部署区域 | 缺失则 P1 |
| 合同、DPA、SLA、安全附件、审计权 | 缺合同则不得低风险 |
| 转委托、子处理者、跨境、数据删除和退出 | 缺失则上线前整改 |
| IP/开源/成果归属、责任限制、赔偿 | 技术/内容/模型供应商必需 |

## 3. 执行流程

1. 判断供应商角色：委托处理、共同处理、独立第三方、技术服务、外包。
2. 审查数据条款：目的、范围、保密、安全、转委托、跨境、删除、审计。
3. 审查服务条款：SLA、事故通知、漏洞修复、可用性、退出迁移。
4. 审查 IP 和开源：成果归属、第三方材料、模型输出、侵权赔偿。
5. 输出合同红线、商业 fallback 和上线 gate。

## 4. 缺失材料处理

- 无 DPA 且接触个人信息：P1。
- 境外供应商不明：P1。
- 无事故通知和删除条款：P1/P2。
- 责任上限过低且高风险服务：升级谈判。

## 5. 输出格式

```markdown
# 供应商审查
## 1. 服务和数据角色
## 2. 合同/DPA/SLA 缺口
## 3. 安全、跨境、退出和事故
## 4. IP/开源/责任条款
## 5. Gate 和谈判建议
```

## 6. 质量门槛

- 必须判断数据角色。
- 必须输出合同缺口和 fallback。
- 必须明确是否允许接入生产数据。
