# V1.0.3 Command 执行标准

本标准约束 `/china-compliance:*` 命令，使其从提示模板升级为可执行工作流。

## 1. 命令必须具备的结构

每个 command 文件必须包含：

1. 命令契约；
2. 必需输入；
3. 可选输入；
4. 执行流程；
5. 推荐调用路径；
6. 缺失材料处理；
7. 输出格式；
8. 质量门槛。

## 2. 事实抽取规则

- 先抽事实，再下结论。
- 已确认事实、假设、缺失材料必须分开。
- 用户没有说“不涉及”的事项，不得默认不涉及；应列入待确认。

## 3. 质量门槛

- 输出必须包含场景分类、风险等级、依据状态、待确认材料、整改建议、Gate。
- P0/P1 必须给关闭标准。
- 缺少关键事实时，只能给条件性结论。
- 不能只输出法规清单，必须解释法规与业务事实之间的关系。
