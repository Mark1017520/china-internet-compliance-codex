# /china-compliance:content_governance_review

## 1. 命令契约

- 命令名称：`/china-compliance:content_governance_review`
- 任务类型：内容治理和社区安全审查
- 适用场景：UGC、评论、弹幕、直播、群聊、私信、公众账号、举报申诉、内容推荐
- 目标输出：内容责任、审核机制、账号治理、举报申诉、未成年人保护和应急处置

## 2. 必需输入

| 字段 | 缺失时处理 |
|---|---|
| 内容类型、发布者、传播范围、是否公开 | 缺失则无法定级 |
| 审核方式、关键词/模型/人工队列、时效 | 缺失则 P1 |
| 举报、申诉、封禁、证据留存机制 | 缺失则上线前整改 |
| 是否涉及直播、新闻、未成年人、付费内容 | 逐项未知 |

## 3. 执行流程

1. 判断内容形态和传播风险。
2. 识别违法不良信息、侵权、谣言、低俗、未成年人风险。
3. 检查发布前/发布后审核、举报申诉、账号处罚、证据留存。
4. 检查推荐、热榜、弹窗、直播等放大机制。
5. 输出治理 SOP 和应急升级路径。

## 4. 缺失材料处理

- 无审核机制：P1，公开 UGC 不建议上线。
- 无举报申诉：P1/P2。
- 直播或新闻属性不明：升级核验。

## 5. 输出格式

```markdown
# 内容治理审查
## 1. 内容形态和传播范围
## 2. 审核和处置机制
## 3. 举报申诉和证据留存
## 4. 高风险内容和未成年人保护
## 5. 上线 Gate
```

## 6. 质量门槛

- 必须说明审核节点和处置闭环。
- 必须覆盖举报申诉。
- 必须说明内容放大机制风险。
