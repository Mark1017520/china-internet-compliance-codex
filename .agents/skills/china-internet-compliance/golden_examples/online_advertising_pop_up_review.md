# Golden Example — Online Advertising Pop-Up Review

## 1. 输入事实摘要

App 计划上线开屏广告和首页弹窗。开屏广告 5 秒后才出现关闭按钮，首页弹窗关闭按钮较小且与背景颜色接近。广告会跳转第三方落地页，当前未提供广告主资质、落地页审核、广告标识、关闭体验测试和投放留痕。

## 2. 结论前置

- 风险等级：P1 高风险
- 上线建议：补齐显著广告标识、一键关闭、广告主/落地页审核和投放留痕后再上线
- 核心理由：弹窗广告应可识别且可一键关闭，不能通过延迟关闭、弱化关闭按钮或诱导点击影响用户选择；第三方落地页还可能带来虚假宣传、资质和恶意下载风险。

## 3. 事实矩阵

| 事实项 | 内容 | 状态 |
|---|---|---|
| 广告形式 | 开屏广告、首页弹窗 | 高关注 |
| 关闭按钮 | 5 秒后出现/不显著 | 高风险 |
| 跳转 | 第三方落地页 | 高风险 |
| 广告标识 | 未提供 | 缺失 |
| 审核材料 | 未提供 | 缺失 |
| 留痕 | 未说明 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 关闭障碍 | P1 | 延迟出现关闭按钮、按钮不显著 | 首屏显著、一键关闭，不误导点击 |
| 广告可识别性不足 | P1 | 未标明广告 | 显著标注“广告”和广告主/来源 |
| 落地页审核不足 | P1 | 跳转第三方页面 | 审核资质、内容、下载链路和备案信息 |
| 特殊广告资质风险 | P1 | 未说明行业 | 医疗、金融、教育等需专项资质和文案审核 |
| 投放留痕不足 | P2 | 未说明审核记录 | 保留素材、版本、审核、投放和下架记录 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 开屏和弹窗均设置显著、稳定、一键关闭按钮 | 产品/前端 | 上线前 |
| 标明“广告”，不得伪装系统通知或内容入口 | 商业化/产品 | 上线前 |
| 建立广告主资质、素材、落地页和下载链路审核 | 商业化/法务/安全 | 上线前 |
| 特殊行业广告进入医疗、金融、教育等专项审批 | 法务/商业化 | 上线前 |
| 建立投放巡检、投诉下架和素材留痕机制 | 广告运营/客服 | 灰度前 |

## 6. 上线 Gate

关闭按钮未显著且无法一键关闭前，不建议上线。第三方落地页未经审核时，不得投放至全量用户。

## 7. 依据状态

- 待核验依据：互联网广告、弹窗信息推送、消费者权益、特殊广告资质和平台广告审核规则需核验最新版官方文本。
- 内部规则/风险偏好：开屏和弹窗广告默认纳入商业化 P1 gate。

## 8. 可复制评审结论

【结论】当前开屏和首页弹窗方案存在关闭障碍和第三方落地页审核缺失，不建议上线。应按 P1 处理，改为显著标识广告、一键关闭、完成广告主和落地页审核，并建立投放留痕、巡检和投诉下架机制。
