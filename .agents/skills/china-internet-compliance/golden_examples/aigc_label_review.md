# 优秀样例：AIGC内容标识评审

## 输入摘要
平台允许创作者使用AI生成商品短视频和营销海报，并发布到站内内容流。当前计划只在后台记录AI生成，不在前台展示。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：仅后台记录不充分；面向用户展示的AI生成内容应设置显式标识，并保留隐式标识能力。

### 2. 主要风险
1. 用户可能误以为商品图、短视频为真实拍摄或真实体验。
2. AI营销素材可能构成广告或商业推广，应同时满足广告真实性和可识别性。
3. 若涉及虚假场景、夸大效果、公众人物或第三方素材，存在侵权与虚假宣传风险。

### 3. 整改建议
- 在内容卡片、视频角标、详情页展示“AI生成/AI辅助生成”。
- 元数据或水印中保留隐式标识。
- 对商品功效、价格、库存、活动信息要求引用真实数据，不得由模型编造。
- 对创作者提供AI素材发布规范和违规处罚规则。

### 4. 可复制评审结论
AI生成营销素材面向公众传播，需同时满足AIGC标识、广告真实性和平台内容治理要求。建议按P1处理，补充前台显式标识、隐式标识、素材审核和广告文案校验后上线。
