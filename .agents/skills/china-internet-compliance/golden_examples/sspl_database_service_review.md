# 优秀样例：SSPL数据库/服务组件评审

## 输入摘要
研发计划使用SSPL许可证数据库作为生产业务数据库，存储用户订单和日志，不修改源码，不对外出售数据库服务。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：SSPL属于高风险许可证，应优先使用官方商业许可、云厂商合规版本或替代数据库。

### 2. 主要风险
1. SSPL对“作为服务提供”的场景要求非常强，可能要求开放服务管理相关代码。
2. 即使只是内部生产数据库，也需确认具体版本、发行渠道、许可证变更和商业条款。
3. 存储生产用户数据还涉及数据安全、备份、权限、日志和供应商支持问题。

### 3. 整改建议
- 确认版本、许可证和发行包来源。
- 优先采购商业授权或替换为宽松许可证数据库。
- 避免基于SSPL组件对外提供数据库托管或相似服务。
- 完成数据安全和运维安全评估。

### 4. 可复制评审结论
SSPL组件不宜按普通开源组件处理。即使未修改源码，也建议按P1进行许可证专项评估，优先选择商业许可或替代方案，避免未来服务化或私有化交付触发高风险义务。
