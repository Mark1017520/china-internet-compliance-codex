# Golden Example — Financial Lead Generation Review

## 1. 输入事实摘要

平台计划在商家后台展示“经营贷测额”入口，用户填写手机号、营业执照、店铺流水和联系人信息后跳转至合作金融机构。页面文案写“最快 1 分钟放款”“额度最高 100 万”“通过率 98%”。合作方资质、导流协议、用户授权和数据共享清单尚未提供。

## 2. 结论前置

- 风险等级：P1 高风险；若平台实质参与授信、定价、放款或资金撮合，可能升级为 P0
- 上线建议：明确平台仅作信息展示/导流边界，核验持牌主体和金融广告文案，签署数据共享/DPA，并补齐用户授权后再上线
- 核心理由：金融导流同时触发金融广告、持牌主体、个人信息共享、消费者权益和反误导宣传风险。

## 3. 事实矩阵

| 事实项 | 内容 | 状态 |
|---|---|---|
| 服务 | 经营贷测额导流 | 高风险 |
| 数据 | 手机号、营业执照、流水、联系人 | 高关注 |
| 文案 | 1 分钟放款、100 万、通过率 98% | 高风险 |
| 合作方资质 | 未提供 | 缺失 |
| 数据共享授权 | 未提供 | 缺失 |
| 平台角色 | 未明确 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 持牌主体和平台边界不清 | P1/P0 | 经营贷测额导流 | 核验金融机构资质，平台不得无牌开展金融业务 |
| 金融广告文案误导 | P1 | 放款速度、额度、通过率承诺 | 删除绝对化和无法证明的承诺 |
| 个人信息共享不足 | P1 | 向合作方提供联系方式和经营数据 | 单独同意、共享清单、接收方和用途披露 |
| 数据安全和供应商责任不足 | P1 | 合作方处理商家经营数据 | 签署 DPA、安全附件和删除/投诉条款 |
| 投诉和责任承担不清 | P2 | 贷款争议可能回流平台 | 明确客服分工、投诉转办和页面免责声明 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 核验合作金融机构资质、产品资质和授权链 | 法务/采购 | 上线前 |
| 删除“最快”“最高”“通过率”等无法证明或绝对化文案 | 商业化/法务 | 上线前 |
| 用户提交前展示接收方、字段、用途、联系方式并取得单独同意 | 产品/隐私 | 上线前 |
| 签署导流协议、DPA、安全附件和投诉处理机制 | 法务/采购/客服 | 上线前 |
| 限制平台参与授信、风控、定价、资金流和还款催收 | 业务/法务 | 上线前 |

## 6. 上线 Gate

未核验持牌主体、金融广告文案和数据共享授权前，不建议上线。平台不得在无资质情况下实质参与金融业务或以平台名义作收益/放款承诺。

## 7. 依据状态

- 待核验依据：金融广告、互联网贷款/助贷、个人信息共享、消费者权益和反不正当竞争规则需核验最新版官方文本。
- 事实假设：平台仅计划导流，不直接放款或定价。

## 8. 可复制评审结论

【结论】经营贷导流应按 P1 金融相邻场景审查。上线前需核验合作方持牌资质和平台角色，删除误导性金融广告文案，补齐用户单独同意、数据共享清单、DPA 和投诉处理。若平台实质参与授信、资金或催收，应阻断并重新评估资质路径。
