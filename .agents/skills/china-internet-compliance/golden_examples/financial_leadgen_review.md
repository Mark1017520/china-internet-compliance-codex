# 优秀样例：金融产品导流评审

## 输入摘要
App计划展示贷款产品列表，用户填写手机号、收入、职业后，由合作金融机构联系用户。页面文案包含“最高可借50万，极速放款，低息无忧”。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：需明确持牌金融机构主体、导流边界、用户授权、金融广告审查和风险提示。

### 2. 主要风险
1. 平台不得被用户误认为贷款提供方或承诺审批结果。
2. 收入、职业、手机号用于金融导流，涉及个人信息和可能的敏感金融场景。
3. “极速放款”“低息无忧”等表述可能构成误导性金融广告。
4. 若平台参与风控评分、额度审批或资金撮合，可能触及金融许可边界。

### 3. 整改建议
- 页面明确展示持牌机构名称、资质、服务边界。
- 文案删除承诺式、绝对化、收益/通过率暗示。
- 单独告知并取得向金融机构提供个人信息的同意。
- 签署合作协议和DPA，限制用途。
- 不参与授信审批、定价和资金流转，除非具备资质。

### 4. 可复制评审结论
贷款导流功能涉及金融广告、个人信息对外提供和许可边界风险。建议按P1处理，完成持牌主体展示、文案审查、单独同意、DPA和业务边界隔离后再上线。
