# Golden Example — Cross-Border Standard Contract Review

## 1. 输入事实摘要

跨境客服系统拟将中国大陆用户订单号、收货人姓名、手机号、地址、售后沟通记录同步至境外客服供应商，用于工单处理和质检。预计日活用户约 8 万，境外供应商可能将数据存储在新加坡和美国。当前未提供个人信息出境路径判断、标准合同、个人信息保护影响评估、用户告知文案和供应商安全附件。

## 2. 结论前置

- 风险等级：P1 高风险；如触发安全评估或重要数据/大规模敏感个人信息处理，可能升级为 P0
- 上线建议：完成出境路径判断、PIA、标准合同或其他合法路径、用户告知和供应商约束后再上线
- 核心理由：该场景将中国大陆用户个人信息持续同步至境外供应商，且包含联系方式和地址等高敏感度业务数据。当前合规路径和合同约束均缺失。

## 3. 事实矩阵

| 事实项 | 已知内容 | 状态 |
|---|---|---|
| 数据字段 | 订单号、姓名、手机号、地址、售后记录 | 高关注 |
| 接收方 | 境外客服供应商 | 待主体和区域确认 |
| 存储区域 | 新加坡、美国可能涉及 | 待确认 |
| 出境规模 | 日活约 8 万 | 待按人数/字段统计 |
| 出境路径 | 未判断 | 缺失 |
| 合同与 PIA | 未提供 | 缺失 |

## 4. 主要法律/规则问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 出境合法路径缺失 | P1 | 个人信息同步至境外 | 完成安全评估/认证/标准合同等路径判断 |
| PIA 缺失 | P1 | 持续向境外提供个人信息 | 完成 PIA 并经隐私负责人确认 |
| 用户告知不足 | P1 | 未披露境外接收方和目的 | 更新隐私政策和必要告知 |
| 供应商控制不足 | P1 | 境外供应商处理客服数据 | 签署 DPA、安全附件、子处理者和删除条款 |
| 数据最小化不足 | P2 | 全量地址和沟通记录同步 | 按工单必要字段脱敏或分级同步 |

## 5. 证据缺口

- 数据出境规模统计，包括个人信息主体人数、字段、频率和保存期限
- 境外接收方主体、实际处理地点、子处理者和访问人员范围
- PIA 报告、出境路径判断和内部审批记录
- 标准合同或其他出境合规文件
- 用户告知页面、隐私政策和供应商安全测评材料

## 6. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 输出数据出境清单和规模测算 | 数据/研发/隐私 | 上线前 |
| 判断适用安全评估、认证或标准合同路径 | 法务/隐私 | 上线前 |
| 完成 PIA、标准合同和必要备案/报送动作 | 法务/隐私 | 上线前 |
| 与供应商签署 DPA、安全附件、子处理者和删除审计条款 | 法务/采购/安全 | 上线前 |
| 设计字段最小化、脱敏、访问控制、日志和应急下线机制 | 研发/安全 | 上线前 |

## 7. 上线 Gate

未完成出境路径判断和 PIA 前不得接入生产数据。若最终适用标准合同路径，应在标准合同、必要备案材料和供应商安全条款完成后再灰度；若触发安全评估，应按安全评估完成情况决定上线。

## 8. 依据状态

- 待核验依据：个人信息出境安全评估、标准合同、促进和规范数据跨境流动相关规则需核验最新版官方文本。
- 事实假设：该服务面向中国大陆用户且境外供应商可访问原始个人信息。

## 9. 可复制评审结论

【结论】该跨境客服同步方案目前不建议上线。项目应按 P1 处理，先完成数据出境规模测算、合法路径判断、PIA、标准合同或其他出境文件、用户告知和供应商 DPA/安全附件。生产数据不得在路径未闭合前传输至境外供应商。
