# 优秀样例：直播间抽奖活动评审

## 输入摘要
直播间用户充值获得抽奖次数，可抽虚拟礼物、现金券和主播连麦资格。活动面向全量用户，包括未成年人。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1，若面向未成年人且与充值强绑定，部分设计可能P0阻断。
- **上线建议**：不得面向未成年人开放充值抽奖；需明确概率、奖品、限制和反赌博化设计。

### 2. 主要风险
1. 充值换抽奖次数容易被认定为诱导消费或赌博化设计。
2. 概率、奖品价值、中奖限制不透明会引发消费者权益和广告营销风险。
3. 未成年人参与充值抽奖风险极高。
4. 主播引导话术可能构成虚假宣传或诱导打赏。

### 3. 整改建议
- 未成年人禁用充值抽奖和高价值打赏。
- 公示中奖概率、奖品数量、限制条件、有效期、退款规则。
- 设置消费上限、冷静期和风险提示。
- 主播话术审核，禁止“必中”“稳赚”“翻倍”等表述。
- 留存活动配置、概率、开奖和中奖记录。

### 4. 可复制评审结论
直播充值抽奖叠加未成年人、虚拟资产、广告营销和消费者权益风险。建议按P1处理，未成年人参与部分应阻断，完成概率公示、规则透明、消费限制和主播话术审核后再上线。
