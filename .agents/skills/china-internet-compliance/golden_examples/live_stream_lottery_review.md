# Golden Example — Live Stream Lottery Review

## 1. 输入事实摘要

直播间计划上线“下单满 99 元参与抽奖”活动，奖品包括现金红包、平台券和实物礼品。主播可在后台设置中奖概率和奖品池，用户需要在直播间停留并完成购买才能参与。活动规则页尚未明确概率、开奖方式、奖品数量、限制条件、未成年人参与规则和异常订单处理。

## 2. 结论前置

- 风险等级：P1 高风险；若形成付费抽奖、诱导充值或现金化，可能升级为 P0
- 上线建议：完成活动规则、概率/奖品披露、反赌博化、未成年人限制和广告/促销审查后再上线
- 核心理由：直播场景具有强促销和即时互动属性，付费门槛叠加概率中奖容易触发消费者权益、广告促销、反不正当竞争、赌博化和未成年人保护风险。

## 3. 事实矩阵

| 事实项 | 已知内容 | 状态 |
|---|---|---|
| 参与条件 | 下单满 99 元、直播间停留 | 高关注 |
| 奖品 | 现金红包、平台券、实物礼品 | 高关注 |
| 概率设置 | 主播后台可调 | 高风险 |
| 活动规则 | 未完整披露 | 缺失 |
| 未成年人 | 未说明限制 | 缺失 |
| 异常处理 | 未说明退款/刷单/争议 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 付费抽奖边界不清 | P1 | 下单后才可参与 | 规则证明为合法促销，不得诱导赌博化 |
| 概率和奖品不透明 | P1 | 后台概率可调 | 公示中奖概率、奖品数量、调整审批和留痕 |
| 现金红包风险 | P1 | 奖品含现金权益 | 限定使用范围、不得提现或变相返现套利 |
| 未成年人保护缺失 | P1 | 直播间可能有未成年人 | 禁止或严格限制未成年人参与 |
| 主播宣传失控 | P1 | 直播口播影响购买决策 | 审核话术，禁止保底中奖、夸大概率和虚假承诺 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 完整活动规则：参与条件、奖品、概率、开奖、发放、退款和争议 | 运营/法务 | 上线前 |
| 固定概率配置，变更需审批、版本号和生效时间留痕 | 研发/运营 | 上线前 |
| 将现金红包改为不可提现的平台优惠权益，防套利 | 运营/支付/法务 | 上线前 |
| 设置未成年人禁止参与或严格限制机制 | 产品/风控 | 上线前 |
| 建立主播话术审核、实时巡检、投诉处理和活动回滚 | 直播运营/内容安全 | 灰度前 |

## 6. 上线 Gate

未完成规则披露、概率留痕、现金化限制和未成年人保护前，不建议上线。灰度期间应限制活动规模和奖品总额，实时监控投诉、退款、刷单和异常中奖。

## 7. 依据状态

- 待核验依据：广告促销、反不正当竞争、消费者权益、直播营销和未成年人保护相关规则需核验最新版官方文本。
- 内部规则/风险偏好：付费门槛加概率奖励应作为直播高风险促销专项审批。

## 8. 可复制评审结论

【结论】直播“下单满额抽奖”不能按普通营销活动上线。建议按 P1 处理，补齐活动规则、概率和奖品披露、后台变更留痕、现金化限制、主播话术审核和未成年人保护后再灰度。若奖品可提现或诱导持续付费，应阻断上线。
