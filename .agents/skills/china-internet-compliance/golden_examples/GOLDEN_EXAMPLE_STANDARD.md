# Golden Example Standard

Golden examples should read like real internal legal/compliance review notes, not generic risk reminders.

## Required Structure

1. 输入事实摘要
2. 结论前置
3. 事实矩阵
4. 触发的合规维度
5. 主要法律/规则问题
6. 证据缺口
7. 整改建议和责任方
8. 上线 Gate 或响应 Gate
9. 依据状态
10. 可复制评审结论

## Quality Rules

- Each risk must tie to a concrete fact.
- P0/P1 risks must include evidence gaps and closure standards.
- Legal basis must be marked as verified, pending verification, internal rule or factual assumption.
- Outputs should include practical next steps, not only risk descriptions.
- High-risk matters should not end with only “consult counsel”; the example must still provide an initial gate and work plan.
