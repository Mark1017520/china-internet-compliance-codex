# 优秀样例：企业RAG知识库评审

## 输入摘要
企业内部AI助手接入合同、客户邮件、工单和代码仓库作为RAG知识库，员工可提问并生成答复。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：需补充知识库授权边界、权限继承、脱敏、审计日志和提示注入防护。

### 2. 主要风险
1. 知识库包含个人信息、客户保密信息、合同秘密和源代码。
2. RAG可能越权检索员工无权访问的文档。
3. 用户提示注入可能诱导模型输出敏感信息。
4. 输出内容可能被复制到外部，造成泄密。

### 3. 整改建议
- RAG检索权限继承原系统权限，不得突破文档ACL。
- 高敏文档默认不入库或脱敏入库。
- 记录检索、回答、引用文档和导出日志。
- 设置外发水印和敏感信息拦截。
- 对代码、客户数据、合同设置分类分级和审批。

### 4. 可复制评审结论
企业RAG功能涉及客户数据、合同秘密、代码和内部权限。建议按P1处理，完成权限继承、知识库分级、脱敏、审计和提示注入防护后再上线。
