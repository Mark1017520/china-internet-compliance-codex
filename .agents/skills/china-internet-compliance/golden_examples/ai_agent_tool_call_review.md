# Golden Example — AI Agent Tool Call Review

## 1. 输入事实摘要

某企业 SaaS 客服产品拟上线 AI Agent。Agent 可读取企业知识库，调用订单系统查询订单状态，并在客户同意后自动发送售后邮件。模型由第三方 API 提供，当前材料未说明模型部署区域、是否保留会话用于训练、工具调用权限边界和人工复核机制。

## 2. 结论前置

- 风险等级：P1 高风险
- 上线建议：整改后灰度上线
- 核心理由：该功能同时触发 AI/AIGC、个人信息处理、供应商数据处理、自动化工具调用和对外客户沟通风险。当前缺少模型供应商 DPA、工具调用权限控制、AIGC 标识、人工兜底和日志留存材料，不宜直接全量上线。

## 3. 事实矩阵

| 事实项 | 已知内容 | 状态 |
|---|---|---|
| 使用场景 | 售后客服自动回复和邮件发送 | 已确认 |
| 数据类型 | 订单状态、客户咨询、企业知识库 | 待细化字段 |
| 模型供应商 | 第三方 API | 待确认部署区域和训练用途 |
| 工具调用 | 订单查询、邮件发送 | 待确认权限边界 |
| 用户告知 | 未提供页面和文案 | 缺失 |
| 人工复核 | 复杂问题转人工，但规则不明 | 待确认 |

## 4. 触发的合规维度

- 个人信息处理：订单信息、咨询内容可能包含个人信息。
- AI/AIGC：AI 自动生成回复并可能影响消费者权益。
- 供应商管理：第三方模型 API 接触业务数据。
- 自动化工具调用：Agent 可查询订单和发送邮件，需要权限控制。
- 消费者权益：错误回复可能影响退款、售后、履约承诺。

## 5. 主要法律/规则问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 模型供应商数据处理责任不清 | P1 | 第三方 API 接收咨询和订单上下文 | 补 DPA、部署区域、训练用途、删除和审计条款 |
| Agent 工具调用越权风险 | P1 | 可调用订单系统和发送邮件 | 建立最小权限、审批、操作日志和失败回滚 |
| AI 生成内容标识不足 | P1 | 自动回复客户 | 页面和邮件中显著标识 AI 生成/自动回复 |
| 错误售后承诺风险 | P1 | 自动发送售后邮件 | 高风险场景转人工，建立纠错和投诉流程 |
| 知识库内容泄露风险 | P2 | 读取企业知识库 | 做权限隔离、敏感词过滤和日志留存 |

## 6. 证据缺口

- 模型供应商 DPA、安全附件和部署区域说明
- 是否使用客户会话或订单数据训练/优化模型
- 工具调用权限矩阵、操作日志和风控策略
- AI 标识文案、用户告知和隐私政策更新
- 人工复核、申诉纠错、客服接管和回滚 SOP

## 7. 整改建议与责任方

| 整改项 | 责任方 | 优先级 |
|---|---|---|
| 补充模型供应商 DPA 和跨境/训练用途说明 | 法务/隐私/采购 | P1 |
| 为订单查询和邮件发送设置最小权限、审批和审计日志 | 研发/安全 | P1 |
| 增加 AI 标识和用户告知文案 | 产品/法务 | P1 |
| 设置退款、赔付、投诉等高风险意图强制转人工 | 产品/客服运营 | P1 |
| 建立灰度监控指标：误答率、转人工率、投诉率、工具调用失败率 | 产品/数据 | P2 |

## 8. 上线 Gate

整改后灰度上线。灰度比例不超过低风险商家范围；涉及退款金额、法律承诺、投诉升级、敏感个人信息的会话必须转人工。P1 项全部关闭前不得全量上线。

## 9. 依据状态

- 待核验依据：AI/AIGC、个人信息保护、数据出境和供应商数据处理相关规则需核验最新版官方文本。
- 内部规则/风险偏好：Agent 工具调用需按公司生产系统权限审批规则执行。
- 事实假设：默认第三方模型 API 可接触客户咨询和订单上下文。

## 10. 可复制评审结论

【结论】该 AI Agent 功能目前不建议直接全量上线。基于现有材料，第三方模型数据处理、工具调用权限、AI 标识、人工兜底和日志留存均存在上线前缺口。建议按 P1 高风险整改，完成 DPA、权限控制、AI 标识和人工复核机制后，仅在低风险场景灰度上线并持续监控。
