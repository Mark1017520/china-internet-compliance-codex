# 优秀样例：境外大模型API处理用户数据评审

## 输入摘要
产品拟接入境外大模型API，为中国大陆用户生成客服回复。输入内容可能包含订单号、手机号、地址和聊天记录。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1，若含敏感个人信息或大规模客户数据，可能升至P0/P1阻断。
- **上线建议**：不得直接将原始用户数据发送境外模型；需先完成数据最小化、脱敏、跨境路径判断和供应商合同审查。

### 2. 主要风险
1. 将用户聊天记录、手机号、地址、订单发送境外模型，可能构成个人信息出境。
2. 客服记录可能包含敏感信息和用户投诉内容，需做PIA。
3. 模型供应商可能将输入用于训练或服务改进，需合同明确禁止或限制。
4. AI回复可能产生错误承诺、违法内容或消费者权益风险。

### 3. 法律/规则依据
- 个人信息保护法关于个人信息出境、单独同意、PIA和委托处理/对外提供的规则。
- 数据出境配套规则关于安全评估、标准合同、认证或便利化条件的路径判断。
- 生成式AI服务规则关于内容安全、投诉纠错和服务治理的要求。

### 4. 整改建议
- 使用本地模型或境内代理服务优先。
- 对手机号、地址、订单号做脱敏或摘要化。
- 明确模型供应商不得训练、不得再分包、按期删除。
- 完成跨境数据路径判断：是否需标准合同、认证、安全评估或适用便利化条件。
- AI客服回复涉及退款、赔偿、法律承诺的，设置人工复核。

### 5. 可复制评审结论
该功能涉及境外模型处理中国大陆用户个人信息和客服记录，当前不得直接发送原始数据。建议按P1处理，完成脱敏、PIA、跨境合规路径、供应商DPA和人工复核机制后再评估上线。
