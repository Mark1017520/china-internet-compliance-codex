# Golden Example — Algorithm Filing Gap Review

## 1. 输入事实摘要

资讯 App 计划调整首页推荐排序模型，新增基于点击、停留、收藏、关注、地理位置和设备信息的个性化分发，并形成兴趣画像。产品材料未说明是否属于互联网信息服务算法推荐、是否需要备案、是否提供关闭个性化推荐入口、是否面向未成年人，以及是否有算法安全评估报告。

## 2. 结论前置

- 风险等级：P1 高风险
- 上线建议：完成算法备案触发判断、用户选择权和内容安全评估后再上线
- 核心理由：首页推荐影响信息分发，且使用用户画像进行个性化排序。当前缺少备案判断、算法机制说明、关闭入口和内容治理留痕，不宜直接全量发布。

## 3. 事实矩阵

| 事实项 | 已知内容 | 状态 |
|---|---|---|
| 服务形态 | 资讯 App 首页推荐 | 高关注 |
| 算法类型 | 个性化排序/推荐 | 已知 |
| 使用数据 | 点击、停留、关注、地理位置、设备信息 | 待字段核验 |
| 是否备案 | 未评估 | 缺失 |
| 用户关闭入口 | 未设计 | 缺失 |
| 内容安全评估 | 未提供 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 算法备案判断缺失 | P1 | 首页推荐可能具有信息分发影响 | 完成备案触发判断和材料清单 |
| 个性化推荐关闭入口缺失 | P1 | 使用用户画像排序 | 提供关闭/不针对个人特征选项 |
| 内容放大风险 | P1 | 推荐可能放大违法有害或低质内容 | 建立召回、降权、人工干预和审核规则 |
| 数据最小化不足 | P1 | 使用地理位置、设备信息 | 删除非必要字段或完成必要性论证 |
| 未成年人保护缺失 | P1 | App 可能被未成年人使用 | 建立未成年人模式和沉迷防控策略 |

## 5. 证据缺口

- 算法说明文档、推荐目标、主要特征和干预规则
- 备案触发分析和备案材料准备状态
- 隐私政策、用户关闭入口和页面截图
- 内容安全策略、人工干预 SOP 和日志字段
- 未成年人使用场景评估

## 6. 整改建议与责任方

| 整改项 | 责任方 | Gate |

## 7. 上线 Gate

在备案判断、关闭入口、内容安全评估和隐私披露未完成前，不建议上线。若判断应备案，应按备案路径推进，不应以“模型只是排序”作为免审理由。

## 8. 依据状态

- 待核验依据：算法推荐服务、个人信息保护、未成年人网络保护和内容治理相关规则需核验最新版官方文本。
- 事实假设：该推荐服务面向中国大陆公众用户提供信息分发。

## 9. 可复制评审结论

【结论】该首页推荐改版不宜直接上线。建议按 P1 处理，先完成算法备案触发判断、个性化推荐关闭入口、隐私披露、内容安全评估和未成年人保护策略。P1 项关闭后可灰度，灰度期间需监测推荐投诉、关闭率和违法有害内容拦截情况。
