# 优秀样例：AI头像生成功能评审

## 输入摘要
用户上传真人照片，系统生成AI头像，可下载并发布到社区。模型由第三方提供，生成图默认不显示AI标识。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：需补充人像授权、敏感信息PIA、AI生成标识、违规内容拦截和第三方模型合同后上线。

### 2. 主要风险
1. 真人照片可能涉及生物识别、肖像权和敏感个人信息风险。
2. AI生成头像可能误导为真实照片，需设置AI生成标识。
3. 模型可能生成侵权、色情低俗、仿冒公众人物或冒用他人肖像内容。
4. 第三方模型是否保留、训练用户照片需明确。

### 3. 整改建议
- 上传页明确告知用途、保存期限、是否用于训练、删除方式。
- 取得单独同意；未成年人使用需监护人授权或限制。
- 默认添加显式AI生成标识；保留隐式标识或水印能力。
- 禁止生成公众人物、身份证件、色情低俗、欺诈头像。
- 生成后提供删除、举报和申诉。

### 4. 可复制评审结论
AI头像功能同时触发敏感个人信息、肖像权、AIGC标识和内容安全风险。建议按P1处理，完成单独同意、PIA、AI标识、模型供应商限制和内容审核机制后再上线。
