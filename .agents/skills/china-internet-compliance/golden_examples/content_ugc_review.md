# 优秀样例：UGC社区功能评审

## 输入摘要
App新增社区模块，用户可发帖、评论、上传图片，支持关注、私信和举报。当前只设计机器审核，未设计人工复核和申诉。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：需补充内容审核、举报、人工复核、账号处置、申诉和日志留存机制。

### 2. 主要风险
1. UGC可能产生违法有害信息、色情低俗、诈骗、赌博、侵权内容。
2. 仅机器审核可能无法覆盖语义变体、图片文本、隐晦引流。
3. 账号处罚无申诉机制，容易引发用户权益争议。
4. 私信功能增加诈骗、骚扰、未成年人风险。

### 3. 整改建议
- 建立发布前/发布后审核策略。
- 设置举报入口、处置时限、处罚规则和申诉流程。
- 高风险内容进入人工复核。
- 私信增加反诈、拉黑、举报和未成年人保护。
- 留存内容、审核、举报、处置日志。

### 4. 可复制评审结论
社区UGC功能触发内容治理和平台主体责任。当前仅机器审核不足，建议按P1处理，补齐举报、人工复核、账号处罚申诉、日志留存和私信风控后上线。
