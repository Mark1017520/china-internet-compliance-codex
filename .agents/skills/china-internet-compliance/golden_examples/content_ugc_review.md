# Golden Example — Content UGC Review

## 1. 输入事实摘要

App 新增社区模块，用户可发帖、评论、上传图片，支持关注、私信和举报。当前只设计机器审核，未设计人工复核、处罚申诉、私信风控、未成年人保护和日志留存标准。

## 2. 结论前置

- 风险等级：P1 高风险
- 上线建议：补齐内容审核、举报处置、人工复核、账号处罚申诉、私信风控和日志留存后灰度上线
- 核心理由：UGC 社区会持续产生违法有害信息、侵权、诈骗、骚扰和未成年人风险，仅机器审核不足以支撑公开社区上线。

## 3. 事实矩阵

| 事实项 | 内容 | 状态 |
|---|---|---|
| 发布能力 | 发帖、评论、图片 | 高风险 |
| 社交能力 | 关注、私信 | 高风险 |
| 审核方式 | 仅机器审核 | 不充分 |
| 举报 | 有入口但流程不明 | 待完善 |
| 申诉 | 未设计 | 缺失 |
| 日志留存 | 未说明 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 违法有害内容处置不足 | P1 | UGC 发帖和图片 | 机器+人工复核、分级处置和下架机制 |
| 举报和申诉缺失 | P1 | 用户可被处罚或内容下架 | 设定举报入口、处理时限、申诉和复核 |
| 私信诈骗和骚扰风险 | P1 | 支持私信 | 反诈提示、频控、拉黑、举报和未成年人限制 |
| 审核留痕不足 | P1 | 未说明日志 | 保留内容、审核、处置、申诉和操作日志 |
| 未成年人保护不足 | P1 | 社区可能被未成年人使用 | 建立未成年人模式和高风险互动限制 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 建立发布前/发布后审核、关键词/图片识别和人工复核队列 | 内容安全/研发 | 上线前 |
| 制定社区规则、账号处罚规则、举报处理和申诉流程 | 运营/法务 | 上线前 |
| 私信增加反诈、骚扰拦截、频控、拉黑和举报能力 | 产品/安全 | 上线前 |
| 明确内容、审核、举报、处置和申诉日志留存周期 | 安全/运营 | 上线前 |
| 对未成年人限制私信、陌生人互动和沉迷内容推荐 | 产品/风控 | 灰度前 |

## 6. 上线 Gate

未完成人工复核、举报申诉、私信风控和日志留存前，不建议上线公开社区。可先关闭私信，仅开放低风险白名单用户灰度。

## 7. 依据状态

- 待核验依据：网络信息内容治理、未成年人网络保护、个人信息保护和平台治理规则需核验最新版官方文本。
- 内部规则/风险偏好：开放 UGC 和私信默认纳入 P1 内容安全 gate。

## 8. 可复制评审结论

【结论】社区 UGC 功能当前不能仅依赖机器审核上线。建议按 P1 处理，补齐内容审核、举报处置、人工复核、账号处罚申诉、私信反诈和日志留存机制后再灰度；私信能力可作为独立高风险开关延后开放。
