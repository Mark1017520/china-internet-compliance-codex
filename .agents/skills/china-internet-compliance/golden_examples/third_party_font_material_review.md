# Golden Example — Third-Party Font And Material Review

## 1. 输入事实摘要

运营活动海报使用网上下载的字体、人物图片和图标包。设计师称“网站写了免费可商用”，但未保存授权链接、许可证文本、购买订单或素材来源截图。海报将用于 App 开屏、站内 banner、公众号和付费广告投放。

## 2. 结论前置

- 风险等级：P1 高风险；若无法证明授权且已用于付费广告，应立即下线或替换
- 上线建议：未取得可核验授权链前，不得用于商业投放或产品内展示
- 核心理由：字体、图片、图标和人物肖像均可能受著作权、肖像权、商标权或平台授权限制保护。“免费”不等于可商用、可改编、可投放广告或可跨渠道分发。

## 3. 事实矩阵

| 事实项 | 内容 | 状态 |
|---|---|---|
| 素材 | 字体、人物图片、图标包 | 高风险 |
| 来源 | 网上下载 | 待核验 |
| 授权证明 | 未保存 | 缺失 |
| 使用场景 | App、banner、公众号、付费广告 | 商业使用 |
| 是否改编 | 可能二次设计 | 待确认 |
| 肖像/商标 | 人物图片可能涉及 | 待核验 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 授权链缺失 | P1 | 无许可证或订单 | 提供可核验授权链接、文本、订单和截图 |
| 商用范围不明 | P1 | 用于广告和产品展示 | 核验商业使用、广告投放、地域和期限 |
| 改编/分发权限不明 | P1 | 海报二次设计多渠道投放 | 核验改编、复制、信息网络传播和转授权 |
| 肖像/商标风险 | P1 | 人物图片和图标可能含第三方权益 | 获取肖像/商标授权或替换素材 |
| 留痕不足 | P2 | 无素材台账 | 建立素材授权台账和发布前 checklist |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 要求提供授权链接、许可证文本、购买订单和来源截图 | 设计/运营 | 上线前 |
| 核查授权范围：商用、广告、改编、地域、期限、渠道 | 法务/运营 | 上线前 |
| 无法证明授权的字体、图片、图标全部替换为公司素材库或自制素材 | 设计/运营 | 上线前 |
| 对人物图片核验肖像授权和敏感行业使用限制 | 法务/设计 | 上线前 |
| 建立活动素材台账、授权归档和到期提醒 | 运营/法务 | 后续 |

## 6. 上线 Gate

授权链缺失的素材不得上线商业投放。若活动已发布，应先下线或替换争议素材，再补做授权核查和证据留存。

## 7. 依据状态

- 待核验依据：著作权、肖像权、商标权、广告投放和素材平台许可条款需核验具体文本。
- 事实假设：素材将用于商业宣传且面向公众传播。

## 8. 可复制评审结论

【结论】该活动海报素材授权链不足，不建议上线。建议按 P1 处理，未取得可核验授权链接、许可证文本、购买订单或公司素材库证明前，所有第三方字体、图片和图标应替换或下线；人物图片还需单独核验肖像和广告使用授权。
