# 优秀样例：信息流推荐算法评审

## 输入摘要
内容社区首页拟上线个性化推荐流，根据用户浏览、停留、点赞、关注、地理位置和设备信息排序内容。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：应完成算法备案判断、个性化推荐关闭入口、内容安全评估和未成年人保护后上线。

### 2. 主要风险
1. 首页内容推荐可能具有舆论属性或社会动员能力，需要判断算法备案。
2. 浏览、停留、关注、地理位置用于画像，需履行告知和最小必要。
3. 需提供不针对个人特征的选项或关闭个性化推荐入口。
4. 推荐算法可能放大违法有害内容、低俗内容、沉迷内容。

### 3. 整改建议
- 做算法自评估和备案触发判断。
- 隐私政策说明推荐目的、字段和关闭方式。
- 提供“关闭个性化推荐/按时间排序”等选项。
- 对未成年人启用保护模式，避免沉迷推荐。
- 建立推荐内容审核、召回降权、人工干预、投诉机制。

### 4. 可复制评审结论
该功能触发算法推荐、个人信息画像和内容治理风险。建议按P1处理，完成算法备案判断、个性化推荐关闭入口、内容安全策略和未成年人保护机制后再上线。
