# Golden Example — Algorithm Recommendation Review

## 1. 输入事实摘要

内容社区首页拟上线个性化推荐流，根据用户浏览、停留、点赞、关注、地理位置和设备信息排序内容。未提供推荐算法备案判断、关闭个性化推荐入口、未成年人模式、内容安全策略和人工干预记录。

## 2. 结论前置

- 风险等级：P1 高风险
- 上线建议：完成备案触发判断、用户选择权、内容安全和未成年人保护后灰度上线
- 核心理由：首页推荐属于核心分发入口，使用画像数据影响用户接收内容，不能只按普通产品排序优化处理。

## 3. 事实矩阵

| 事实项 | 内容 | 状态 |
|---|---|---|
| 推荐位置 | 社区首页 | 高关注 |
| 特征数据 | 浏览、停留、点赞、关注、地理位置、设备信息 | 待最小化 |
| 用户选择 | 无关闭入口 | 缺失 |
| 未成年人 | 未提供保护模式 | 缺失 |
| 内容治理 | 未提供策略 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 算法治理材料不足 | P1 | 核心分发算法上线 | 完成算法说明、备案判断和安全评估 |
| 用户选择权不足 | P1 | 无关闭个性化推荐入口 | 提供关闭或非个性化排序选项 |
| 数据最小化不足 | P1 | 使用地理位置和设备信息 | 删除非必要字段或完成必要性论证 |
| 内容放大风险 | P1 | 推荐流可能放大违法有害内容 | 建立审核、降权、召回和投诉机制 |
| 未成年人保护不足 | P1 | 社区可能被未成年人使用 | 建立未成年人模式、时长和内容限制 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 输出推荐算法说明、特征清单、干预策略和备案判断 | 算法/法务 | 上线前 |
| 增加关闭个性化推荐和按时间排序入口 | 产品/前端 | 上线前 |
| 更新隐私政策，说明推荐字段、目的和退出方式 | 隐私/产品 | 上线前 |
| 建立内容安全审核、召回降权、人工干预和申诉机制 | 内容安全/运营 | 上线前 |
| 对未成年人启用保护策略和沉迷控制 | 产品/安全 | 灰度前 |

## 6. 上线 Gate

关闭入口、备案判断、内容安全策略未完成前，不建议上线。灰度期间应监测个性化关闭率、内容投诉、未成年人拦截和人工干预次数。

## 7. 依据状态

- 待核验依据：算法推荐、个人信息保护、未成年人网络保护和内容治理规则需核验最新版官方文本。
- 内部规则/风险偏好：核心分发算法默认进入 P1 gate。

## 8. 可复制评审结论

【结论】该信息流推荐算法应按 P1 处理。上线前需完成算法备案触发判断、个性化推荐关闭入口、隐私披露、内容安全评估和未成年人保护机制；不得仅以“提升用户体验”为由直接全量发布。
