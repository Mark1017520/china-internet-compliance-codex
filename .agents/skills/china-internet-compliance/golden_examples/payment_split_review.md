# 优秀样例：平台分账功能评审

## 输入摘要
平台拟为商家和达人提供自动分账功能，用户支付后资金先进入平台账户，再按比例结算给商家和达人。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P0/P1。
- **上线建议**：如平台自持资金并进行分账，可能触及支付/清算许可和资金池风险，未完成持牌路径前不得上线。

### 2. 主要风险
1. 用户资金进入平台账户形成资金沉淀，可能被认定为无牌支付、二清或资金池。
2. 分账涉及商户结算、提现、对账、退款和反洗钱/反诈风险。
3. 平台承担资金安全和交易争议责任。

### 3. 整改建议
- 接入持牌支付机构分账产品，平台不经手客户备付金。
- 资金流、信息流、合同流清晰闭环。
- 商家/达人实名和资质审核。
- 分账规则、退款、冻结、争议处理明确。
- 与支付机构签署协议，明确反洗钱、反诈和数据处理责任。

### 4. 可复制评审结论
该自动分账方案存在支付许可和资金池风险。若平台先收款再自行分账，应阻断上线；建议改为持牌支付机构分账方案，并完成资金流合规和合同审查。
