# Golden Example — Probability Gacha Review

## 1. 输入事实摘要

平台计划上线“幸运宝箱”，用户消耗虚拟币抽取不同等级虚拟道具。道具不可官方提现，但可赠送给其他用户；后台支持运营实时调整概率和奖池。产品材料未说明概率公示、奖池变更记录、未成年人限制、反现金化和异常交易监控。

## 2. 结论前置

- 风险等级：P1 高风险；如存在现金化、二级交易或诱导持续付费，可能升级为 P0
- 上线建议：完成概率公示、后台变更留痕、反赌博化、未成年人限制和消费者告知后再上线
- 核心理由：概率道具玩法容易引发虚假宣传、消费者权益、未成年人沉迷和赌博化争议，尤其是虚拟币消耗与道具赠送功能叠加时。

## 3. 事实矩阵

| 事实项 | 已知内容 | 状态 |
|---|---|---|
| 参与方式 | 消耗虚拟币抽取 | 高关注 |
| 奖品 | 虚拟道具，等级不同 | 已知 |
| 道具流转 | 可赠送 | 高风险 |
| 概率调整 | 后台实时可调 | 高风险 |
| 未成年人限制 | 未说明 | 缺失 |
| 现金化控制 | 未说明 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 概率不透明 | P1 | 用户付费/消耗虚拟币抽取 | 公示概率、奖池、保底规则和有效期 |
| 后台可调缺少留痕 | P1 | 运营可实时调整概率 | 建立审批、版本、时间戳和不可篡改日志 |
| 现金化风险 | P1/P0 | 道具可赠送 | 禁止提现、倒卖、场外交易和兑换现金 |
| 未成年人保护不足 | P1 | 未说明年龄限制 | 禁止或限制未成年人参与概率玩法 |
| 宣传误导风险 | P1 | 活动可能强调稀有道具 | 禁止保底中奖、夸大概率和诱导沉迷话术 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 公示各等级道具概率、奖池、保底、有效期和限制 | 产品/运营/法务 | 上线前 |
| 后台概率调整需审批、版本记录和审计日志 | 研发/运营/安全 | 上线前 |
| 限制赠送链路，拦截场外交易、现金兑换和异常转移 | 风控/安全 | 上线前 |
| 对未成年人禁用或严格限制概率玩法和付费 | 产品/风控 | 上线前 |
| 设置消费提醒、冷静期、投诉退款和活动回滚 | 客服/运营 | 灰度前 |

## 6. 上线 Gate

在概率公示、后台留痕、反现金化和未成年人保护未完成前，不建议上线。若发现道具可提现、可交易或由平台变相回购，应阻断上线并重新设计。

## 7. 依据状态

- 待核验依据：网络游戏/虚拟道具、消费者权益、广告宣传、未成年人保护和反赌博相关规则需核验最新版官方文本。
- 内部规则/风险偏好：概率玩法默认纳入 P1 专项审批。

## 8. 可复制评审结论

【结论】“幸运宝箱”不是普通运营活动，应按 P1 高风险概率玩法审查。上线前必须完成概率和奖池公示、后台调整留痕、反现金化、未成年人限制和误导宣传控制。若存在现金化或二级交易闭环，应按 P0 阻断。
