# Golden Example — Minors Game Recharge Review

## 1. 输入事实摘要

手游计划上线新赛季通行证和限时礼包，未成年人用户可购买月卡、抽取皮肤和参与排行榜。当前仅接入手机号登录，未接入实名校验和未成年人识别；客服计划对未成年人退款按普通退款规则处理。

## 2. 结论前置

- 风险等级：P0/P1
- 上线建议：未完成实名、防沉迷、充值限制、概率玩法限制和未成年人退款 SOP 前，不得向中国大陆用户上线相关付费能力
- 核心理由：游戏付费和概率玩法涉及未成年人保护、实名制、防沉迷、充值限额、消费者权益和平台投诉风险。当前缺少基础实名和付费限制，属于上线阻断项。

## 3. 事实矩阵

| 事实项 | 已知内容 | 状态 |
|---|---|---|
| 产品类型 | 手游赛季通行证、礼包、皮肤抽取 | 高风险 |
| 用户识别 | 手机号登录，无实名校验 | 阻断 |
| 未成年人限制 | 未提供 | 缺失 |
| 充值能力 | 月卡、礼包、抽取 | 高风险 |
| 客服退款 | 普通退款规则 | 不充分 |
| 排行榜 | 未成年人可参与 | 待评估 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 实名和未成年人识别缺失 | P0 | 无法识别未成年人 | 接入实名和年龄识别机制 |
| 防沉迷和时长限制缺失 | P0/P1 | 游戏服务面向未成年人 | 接入防沉迷策略和登录时段限制 |
| 充值限额缺失 | P1 | 未成年人可购买月卡和礼包 | 按年龄段限制充值并拦截超限 |
| 概率玩法保护不足 | P1 | 未成年人可抽取皮肤 | 禁止或严格限制未成年人参与概率玩法 |
| 退款 SOP 不足 | P1 | 仅普通退款规则 | 建立监护人申诉、证据审核和快速退款路径 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 接入实名校验、年龄识别和防沉迷系统 | 研发/游戏运营 | 上线前阻断项 |
| 对未成年人设置时长、时段、充值金额和概率玩法限制 | 产品/风控 | 上线前 |
| 公示付费规则、概率、奖池、有效期和退款条件 | 运营/法务 | 上线前 |
| 建立未成年人退款和监护人申诉 SOP | 客服/法务 | 上线前 |
| 对排行榜和社交展示增加未成年人保护和隐私限制 | 产品/安全 | 灰度前 |

## 6. 上线 Gate

实名和防沉迷能力未完成前，相关游戏付费能力应 P0 阻断。完成后仍需按 P1 审查通行证、礼包、概率抽取、退款和投诉机制，再小流量灰度。

## 7. 依据状态

- 待核验依据：网络游戏实名、防沉迷、未成年人保护、概率玩法和消费者权益相关规则需核验最新版官方文本。
- 内部规则/风险偏好：中国大陆游戏付费功能默认进入未成年人专项 gate。

## 8. 可复制评审结论

【结论】该新赛季付费能力目前不具备上线条件。未接入实名和未成年人识别时，应 P0 阻断中国大陆上线；后续需补齐防沉迷、充值限制、概率玩法限制、未成年人退款 SOP 和规则公示后，方可进入 P1 灰度审查。
