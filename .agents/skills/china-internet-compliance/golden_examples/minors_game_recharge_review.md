# 优秀样例：未成年人游戏充值评审

## 输入摘要
小游戏内设置虚拟钻石，用户可充值购买皮肤和道具。当前未接入实名系统，仅通过用户自填年龄判断未成年人。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P0/P1。
- **上线建议**：未落实实名和未成年人防沉迷前，不得向中国大陆用户开放充值。

### 2. 主要风险
1. 网络游戏或类游戏运营可能涉及版号/备案和防沉迷要求。
2. 自填年龄不能满足未成年人识别和防沉迷要求。
3. 虚拟钻石充值涉及未成年人付费限制、家长退款纠纷和诱导消费。

### 3. 整改建议
- 判断是否构成网络游戏及是否需版号/备案。
- 接入实名验证和防沉迷系统。
- 对未成年人设置时段、时长、充值限制。
- 禁止未成年人参与高刺激抽奖、排行榜刺激消费。
- 建立家长监护和退款处理机制。

### 4. 可复制评审结论
该小游戏充值功能涉及未成年人保护和网络游戏防沉迷。未完成实名、防沉迷、充值限制和资质判断前，应阻断上线或至少阻断中国大陆充值能力。
