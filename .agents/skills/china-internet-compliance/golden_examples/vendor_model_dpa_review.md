# Golden Example — Model Vendor DPA Review

## 1. 输入事实摘要

公司拟采购第三方大模型 API 用于客服摘要和工单分类。供应商合同仅包含通用服务条款，未提供 DPA、安全附件、子处理者清单、部署区域说明、数据删除承诺和是否使用客户数据训练模型的承诺。

## 2. 结论前置

- 风险等级：P1 高风险
- 合同建议：DPA 和安全附件签署前，不建议接入生产客户数据
- 核心理由：模型供应商可能接触客户咨询、订单、联系方式等个人信息和商业信息，现有合同不足以约束用途、保密、安全、转委托、跨境和退出删除

## 3. 事实矩阵

| 项目 | 内容 | 状态 |
|---|---|---|
| 服务内容 | 客服摘要、工单分类 | 已知 |
| 数据类型 | 客户咨询、订单上下文、联系方式可能出现 | 待字段确认 |
| 部署区域 | 未说明 | 缺失 |
| 训练用途 | 未说明是否用于训练 | 缺失 |
| DPA | 未提供 | 缺失 |
| 子处理者 | 未提供 | 缺失 |

## 4. 主要合同问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 数据用途限制不足 | P1 | 合同未限制训练/再利用 | 明确仅按客户指令处理，不得训练或另用 |
| 跨境和部署区域不明 | P1 | 未说明数据处理地点 | 明确区域、跨境路径和审批要求 |
| 转委托不透明 | P1 | 无子处理者清单 | 提供清单、变更通知和反对权 |
| 删除和退出不足 | P1 | 无删除承诺 | 约定期限、证明和备份删除策略 |
| 安全和事故通知不足 | P1 | 无安全附件 | 加入加密、访问控制、日志、事故通知和审计 |

## 5. 谈判建议

| 条款 | 建议立场 | fallback |
|---|---|---|
| 数据训练 | 禁止使用客户数据训练 | 仅经书面同意和脱敏后用于指定优化 |
| 跨境 | 默认境内处理 | 如跨境，先走跨境合规评估 |
| 子处理者 | 事前披露和变更通知 | 至少提供公开清单和退出权 |
| 事故通知 | 24-48 小时内通知 | 不超过 72 小时 |
| 删除 | 服务终止后限期删除并证明 | 备份按周期覆盖并说明 |
| 责任 | 数据泄露、侵权、违规使用不适用低责任上限 | 设置专项赔偿或更高 cap |

## 6. Gate

未签署 DPA、安全附件并确认部署区域、训练用途和子处理者前，不得接入生产客户数据。可使用脱敏测试数据进行 PoC。

## 7. 依据状态

- 待核验依据：个人信息委托处理、跨境、AI 服务和供应商安全相关规则需核验最新版官方文本。
- 内部规则/风险偏好：生产数据接入模型供应商前需法务、隐私、安全和采购共同审批。

## 8. 可复制评审结论

【结论】当前模型供应商合同不足以支持接入生产客户数据。建议先签署 DPA 和安全附件，明确数据用途限制、禁止训练、部署区域、子处理者、删除退出、事故通知和责任承担。完成前仅允许使用脱敏测试数据 PoC，不得上线生产调用。
