# Golden Example — vendor model dpa review

## 1. 场景

境外大模型供应商提供 API 服务，合同未明确训练使用限制、数据删除和安全事件通知。

## 2. 初步结论

- 风险等级：P1 高风险
- 上线建议：整改后上线
- 主要原因：该场景至少涉及个人信息处理、第三方共享或自动化处理，且现有材料不足以证明已完成告知、授权、合同、安全控制和留痕。

## 3. 主要风险

1. 事实材料不足，不能确认数据字段、接收方、用途和保存期限。
2. 未能证明已完成必要的用户告知、内部审批和供应商约束。
3. 如涉及敏感个人信息、跨境、AI自动化处理或第三方插件，应增加专项 gate。

## 4. 依据与核验状态

| 结论 | 依据状态 | 说明 |
|---|---|---|
| 需要补充数据字段与处理目的 | 待核验依据 | 需结合实际数据地图和隐私规则核验 |
| 需要供应商/第三方责任约束 | 内部规则/风险偏好 | 建议作为公司上线前 gate |
| 不宜直接判断低风险 | 事实假设 | 现有材料不足 |

## 5. 整改建议

| 整改项 | 责任方 | Gate |
|---|---|---|
| 补充完整功能说明、数据字段、第三方接收方和用户流程 | 产品/研发 | 上线前 |
| 完成隐私、合同、安全和日志留痕复核 | 法务/隐私/安全 | 上线前 |
| 增加灰度监测、投诉入口和回滚机制 | 产品/运营/研发 | 上线前 |

## 6. 可复制评审结论

【合规结论】：该功能目前不建议直接上线。基于现有材料，未能充分证明其数据处理、第三方约束、用户告知授权和安全留痕已满足上线要求。建议补充事实材料并完成专项复核后，再按 P1 高风险整改后上线处理。

【风险等级】：P1 高风险。
