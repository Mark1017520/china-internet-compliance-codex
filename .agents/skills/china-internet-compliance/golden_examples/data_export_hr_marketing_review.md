# Golden Example — Data Export HR Marketing Review

## 1. 输入事实摘要

增长团队计划将中国大陆员工和商家联系人名单导出到境外营销自动化平台，用于活动邀约、邮件触达和销售线索评分。字段包括姓名、手机号、邮箱、公司、职位、店铺 GMV 分层、最近登录时间和历史投诉标签。当前未提供数据来源、同意记录、出境路径、退订机制和供应商 DPA。

## 2. 结论前置

- 风险等级：P1 高风险
- 上线建议：完成数据来源合法性、营销同意、出境路径判断、字段最小化、退订机制和供应商 DPA 后再导出
- 核心理由：该方案同时涉及员工/商家个人信息、营销触达、画像评分、投诉标签和境外供应商处理，不能按普通名单同步处理。

## 3. 事实矩阵

| 事实项 | 内容 | 状态 |
|---|---|---|
| 数据主体 | 员工、商家联系人 | 高关注 |
| 字段 | 联系方式、职位、GMV、登录、投诉标签 | 高风险 |
| 用途 | 活动邀约、邮件触达、线索评分 | 高关注 |
| 接收方 | 境外营销平台 | 高风险 |
| 同意/退订 | 未提供 | 缺失 |
| DPA | 未提供 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 数据来源和用途不匹配 | P1 | 将运营/投诉标签用于营销评分 | 核验原始收集目的和兼容性 |
| 营销同意不足 | P1 | 邮件/短信触达 | 提供同意、退订和黑名单机制 |
| 出境路径不明 | P1 | 导出至境外平台 | 完成出境路径和 PIA 判断 |
| 字段过宽 | P1 | GMV 和投诉标签用于评分 | 删除非必要字段或单独审批 |
| 供应商责任不清 | P1 | 境外平台处理联系人数据 | 签署 DPA、子处理者、删除和安全条款 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 区分员工数据、商家联系人数据和销售线索数据来源 | 数据/隐私 | 上线前 |
| 删除投诉标签、GMV 分层等非必要或高敏字段 | 增长/数据/法务 | 上线前 |
| 补齐营销触达授权、退订、黑名单和频控 | 增长/产品 | 上线前 |
| 完成数据出境路径判断、PIA 和供应商 DPA | 法务/隐私/采购 | 上线前 |
| 建立导出审批、字段水印、访问日志和删除证明 | 安全/数据 | 上线前 |

## 6. 上线 Gate

未完成字段最小化、营销同意、出境路径和 DPA 前，不得导出名单。投诉标签和 GMV 分层如无明确必要性，应从营销导出中删除。

## 7. 依据状态

- 待核验依据：个人信息保护、营销触达、数据出境、员工信息和供应商处理相关规则需核验最新版官方文本。
- 内部规则/风险偏好：跨境营销导出默认进入 P1 审批。

## 8. 可复制评审结论

【结论】该 HR/商家联系人名单导出方案不宜直接执行。建议按 P1 处理，先核验数据来源和营销同意，删除非必要画像字段，完成数据出境路径、PIA、供应商 DPA、退订黑名单和导出留痕后再导入境外营销平台。
