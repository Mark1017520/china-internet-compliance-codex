# 优秀样例：公安调证材料评审

## 输入摘要
公安调证函要求提供特定账号在某时间段的登录IP、订单金额和操作日志。业务拟提供全量账号日志、源代码片段和内部风控标签。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1，部分材料超范围应阻断提供。
- **提供建议**：仅按函件主体、案由、账号、时间段和字段范围最小必要提供；源代码、内部风控标签原则上不提供。

### 2. 主要风险
1. 全量账号日志超出函件范围，可能包含无关用户个人信息和商业秘密。
2. 源代码片段、内部风控标签可能泄露安全机制和商业秘密。
3. 整理表与原始日志口径不一致会影响证据可信度。

### 3. 整改建议
- 制作“调证要求—拟提供材料—字段—时间范围—是否超范围”对照表。
- 对IP、订单、操作日志按要求账号和时间段导出。
- 对无关个人信息脱敏。
- 提供字段解释和技术说明，不直接提供源代码。
- 保留内部审批、导出记录和原始数据备份。

### 4. 可复制评审结论
公安调证应坚持文书范围和最小必要原则。当前拟提供全量日志、源代码和内部风控标签存在超范围和商业秘密泄露风险，应剔除或改为字段解释，按函件限定账号、时间和字段提供。
