# 优秀样例：企业开放API评审

## 输入摘要
企业服务平台开放API，第三方开发者可读取企业客户的员工列表、客户资料、订单和客服记录。客户授权后即可使用。

## 合规评审结论

### 1. 初步结论
- **风险等级**：P1。
- **上线建议**：需补充API权限分级、客户管理员授权、开发者协议、DPA、审计日志和应用审核机制。

### 2. 主要风险
1. 企业客户数据可能包含个人信息和商业秘密。
2. 第三方开发者处理数据的法律角色需明确，不能仅凭“客户授权”放任使用。
3. API权限过宽可能导致批量导出和越权访问。
4. 开发者应用可能将数据再出售、训练模型或跨境传输。

### 3. 整改建议
- API scope 最小化，按字段/资源/时间授权。
- 企业管理员授权 + 用户级授权按场景区分。
- 开发者协议和DPA明确用途限制、保密、安全、删除、审计、再分包限制。
- 应用审核、风险分级、调用限流、异常告警。
- 支持客户撤销授权和开发者下架。

### 4. 可复制评审结论
开放API涉及企业客户数据、个人信息和第三方开发者治理。建议按P1处理，完成权限分级、开发者DPA、应用审核、日志审计和撤销机制后上线。
