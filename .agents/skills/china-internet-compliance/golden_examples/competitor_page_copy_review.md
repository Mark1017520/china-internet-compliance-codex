# Golden Example — Competitor Page Copy Review

## 1. 输入事实摘要

产品计划“参考”竞品会员页，包括页面布局、权益名称、图标、文案和价格对比表。设计稿与竞品高度相似，部分文案只替换了品牌名，图标从竞品页面截图后重绘。团队希望在大促前快速上线。

## 2. 结论前置

- 风险等级：P1；如存在直接复制文案、图标、截图或竞品商标，相关页面应 P0 阻断
- 上线建议：删除复制表达，保留功能逻辑参考，完成原创化设计和相似度复核后再上线
- 核心理由：竞品页面的文案、图标、布局组合和权益表达可能构成受保护表达，高度近似还可能引发不正当竞争或混淆争议。

## 3. 事实矩阵

| 事实项 | 内容 | 状态 |
|---|---|---|
| 参考对象 | 竞品会员页 | 已知 |
| 相似范围 | 布局、权益名、图标、文案、价格表 | 高风险 |
| 素材来源 | 截图重绘 | 高风险 |
| 上线时间 | 大促前 | 压缩复核 |
| 原创化证据 | 未提供 | 缺失 |

## 4. 主要问题

| 问题 | 等级 | 触发事实 | 关闭标准 |
|---|---|---|---|
| 著作权侵权风险 | P1/P0 | 文案、图标、页面表达高度近似 | 删除复制内容并形成原创设计 |
| 不正当竞争风险 | P1 | 页面整体观感接近竞品 | 相似度复核低风险，避免混淆或搭便车 |
| 商标/品牌风险 | P0 | 可能引用竞品品牌或截图 | 删除竞品标识和截图来源素材 |
| 留痕不足 | P2 | 无设计过程证据 | 保存需求、草图、素材授权和原创说明 |

## 5. 整改建议与责任方

| 整改项 | 责任方 | Gate |
|---|---|---|
| 删除相同/近似文案、图标、配色组合和权益命名 | 设计/产品 | 上线前 |
| 重新设计信息架构和视觉表达，仅保留可自由参考的功能逻辑 | 设计 | 上线前 |
| 建立竞品参考记录，说明未复制具体表达 | 产品/法务 | 上线前 |
| 对最终稿做相似度复核和素材授权核查 | 法务/设计 | 上线前 |
| 对大促页面增加发布前 IP checklist | 运营/法务 | 后续 |

## 6. 上线 Gate

若页面仍保留竞品文案、图标或截图重绘素材，应阻断上线。完成原创化改造和法务复核后，可按普通营销页面上线。

## 7. 依据状态

- 待核验依据：著作权、商标、反不正当竞争和广告宣传相关规则需核验最新版官方文本及争议案例。
- 事实假设：设计稿与竞品页面在整体视觉和核心表达上高度相似。

## 8. 可复制评审结论

【结论】该会员页不能以“参考竞品”为由复制具体表达。当前方案按 P1 处理；如存在直接复制文案、图标、截图或竞品商标，应 P0 阻断。建议完成原创化重设计、素材授权核查和相似度复核后再上线。
