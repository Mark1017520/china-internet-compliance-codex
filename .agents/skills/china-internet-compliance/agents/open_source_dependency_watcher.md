# Agent Spec — open_source_dependency_watcher

## 目的

监控依赖新增、许可证变化、强 copyleft、SSPL/AGPL/BUSL 等风险。

## 触发方式

- 手动触发：用户要求检查对应事项。
- 定时触发：由外部任务调度系统按日/周/月运行。
- 事件触发：PRD状态变更、依赖变更、SDK清单变更、合同到期、监管函件进入等。

## 输入

- 相关连接器输出；
- 公司 Profile；
- 当前规则库；
- 最近一次审查记录或台账。

## 输出

```markdown
# open_source_dependency_watcher 报告

## 1. 变化摘要
## 2. 影响范围
## 3. 风险等级
## 4. 需补充证据
## 5. 建议动作与责任方
## 6. 是否需要人工复核
```

## 限制

该文件是 agent 设计规范，不代表 Codex 会自动后台运行。需要由外部自动化、任务调度或企业平台调用。
