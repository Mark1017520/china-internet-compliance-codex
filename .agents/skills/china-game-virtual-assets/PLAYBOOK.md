# 中国游戏、虚拟资产与未成年人专项 Playbook

## 审查目标
将输入材料转化为可留痕的专项合规判断，避免泛泛提示。

## 标准工作顺序
1. 用主控 `INPUT_FACT_SCHEMA.md` 抽取事实。
2. 按本专项 `SKILL.md` 的判断树分流。
3. 对 P0/P1 信号逐项排查。
4. 用证据清单反推材料缺口。
5. 给出上线 gate、责任方和关闭标准。

## 不合格输出示例
- 只说“注意合规风险”，没有事实、风险等级和整改项。
- 只列法规名称，没有解释为什么触发。
- 对缺少材料的功能直接给“低风险”。
- 对需要人工复核的事项没有升级。

## 合格输出最低标准
- 至少包含 3 个事实点、3 个风险点、3 个待确认问题、3 个整改项。
- 至少明确一个可执行 gate：阻断、整改后上线、灰度上线或上线后监控。
- 所有 P0/P1 项必须写明依据状态与证据缺口。
